1// SQLCC Core User Manager Module Interface
2// Stage 2 Migration Ready - C++20 Module preparation
3// Migration Phase: Traditional Header with Module Enhancement
4//
5// @file user_manager.h
6// @brief 定义了SQLCC数据库的用户管理器，负责用户认证、权限管理和基于角色的访问控制。
7//
8// @WHY
9// 在多用户数据库系统中，安全性是至关重要的。用户管理和权限控制是实现数据安全的核心。
10// 一个健壮的用户管理器需要解决以下问题：
11// 1. **身份认证 (Authentication)**: 验证用户的合法身份（例如，用户名和密码）。
12// 2. **授权 (Authorization)**: 根据用户的身份和角色，决定其对数据库对象（如表、数据库）的访问权限。
13// 3. **基于角色的访问控制 (RBAC)**: 通过为用户分配角色，简化权限管理。权限赋给角色，用户继承角色权限。
14// 4. **可管理性**: 能够方便地创建、删除、修改用户和角色，以及授予和撤销权限。
15// 5. **安全性**: 密码需要安全存储（哈希），权限检查必须严谨，防止越权操作。
16// 6. **可扩展性**: 随着系统功能的增加，权限模型可能需要扩展。
17// 7. **审计**: 记录权限变更和敏感操作，以便后续审计。
18//
19// 本UserManager旨在提供一个安全、高效且可扩展的用户和权限管理框架，支持RBAC。
20//
21// @WHAT
22// 本文件定义了 `UserManager` 类及其辅助数据结构 (`Role`, `User`, `Permission` 等)。
23// `UserManager` 是实现用户身份认证、角色管理和权限检查的核心服务。
24// 它维护着用户、角色及其权限的内存状态，并提供持久化到文件（或SystemDatabase）的机制。
25//
26// 核心功能包括：
27// - 用户生命周期管理 (创建、删除、修改密码、修改角色)。
28// - 角色生命周期管理 (创建、删除、修改角色名)，并支持角色继承。
29// - 权限授予和撤销 (针对用户或角色，对数据库或表进行操作)。
30// - 细粒度权限检查 (CheckPermission)。
31// - 用户认证 (AuthenticateUser)。
32// - 权限审计和冲突检测 (AuditPermissionChanges, CheckPermissionConflict)。
33// - 持久化机制，能够将用户、角色和权限信息保存到文件或 SystemDatabase。
34//
35// @HOW
36// `UserManager` 的实现遵循以下原则和技术：
37// 1. **数据结构**: 使用 `std::unordered_map` 存储用户和角色信息，实现高效查找。
38// 通过 `PermissionKey` 和 `PermissionKeyHash` 构建 `permission_matrix_`，实现 O(1) 的权限检查。
39// 2. **哈希存储密码**: 用户的密码不直接存储明文，而是存储其安全的哈希值，提高安全性。
40// 3. **基于角色的访问控制 (RBAC)**: 用户被分配一个角色，权限则直接或间接（通过角色继承）赋给角色。
41// `CheckPermission` 会检查用户的当前角色及其继承的所有角色是否拥有所需权限。
42// 4. **权限矩阵 (Permission Matrix)**: 通过将授权信息构建为内存中的哈希表，加速权限检查过程。
43// 5. **SystemDatabase 集成**: `UserManager` 可以与 `SystemDatabase` 交互，实现用户、角色和权限信息的持久化存储和同步。
44// 6. **线程安全**: 使用 `std::mutex` 保护所有对内部数据结构的操作，确保在并发环境下的正确性。
45// 7. **现代 C++ 实践**: 采用智能指针 (`std::shared_ptr`, `std::unique_ptr`) 管理内存，使用 `std::string` 等现代 C++ 数据结构。
46// 8. **前向声明**: 最小化头文件包含，使用前向声明减少编译依赖，加快编译速度。
47//
48// 未来增强点：
49// - 异步权限检查。
50// - 审计日志集成。
51// - 性能指标收集。
52//
53// Key improvements:
54// - Smart pointers for memory safety
55// - Forward declarations to reduce compilation dependencies
56// - Thread-safe operations with mutex protection
57// - Modern C++ data structures and algorithms

122struct PermissionKey {
123 std::string grantee;
124 std::string database;
125 std::string table;
126 std::string privilege;
127
133 bool operator==(const PermissionKey &other) const {
134 return grantee == other.grantee && database == other.database &&
135 table == other.table && privilege == other.privilege;
136 }
137};

143struct PermissionKeyHash {
149 std::size_t operator()(const PermissionKey &key) const {
150 // 使用异或操作组合各个字符串字段的哈希值，以生成一个综合哈希值。
151 return std::hash<std::string>{}(key.grantee) ^
152 std::hash<std::string>{}(key.database) ^
153 std::hash<std::string>{}(key.table) ^
154 std::hash<std::string>{}(key.privilege);
155 }
156};
