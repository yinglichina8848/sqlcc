template<typename T>
class sqlcc::SafeConfigAccessor< T >

A template-based utility for type-safe configuration value access.

This class provides a clean, convenient, and safe API for clients to get values of a specific type (e.g., int, bool, std::string) from a ConfigRAIIAccessor. It handles the complexities of converting from the underlying ConfigValue variant, providing default values and suppressing exceptions for read operations to simplify client code.
