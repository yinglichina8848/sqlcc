# SQLCC 服务器和客户端程序使用说明

## 概述

本项目包含两个主要的可执行程序：

1. **sqlcc** - 服务器端程序，负责处理客户端连接和SQL命令执行
2. **isql** - 客户端程序，用于连接到服务器并发送SQL命令

## 构建程序

使用Bazel构建两个程序：

```bash
# 构建服务器端程序
bazel build //:sqlcc

# 构建客户端程序
bazel build //:isql
```

## 运行服务器

```bash
# 运行服务器（默认端口18647）
./bazel-bin/sqlcc

# 指定端口运行
./bazel-bin/sqlcc -p 18647

# 启用加密模式
./bazel-bin/sqlcc -e
```

## 运行客户端

```bash
# 连接到本地服务器
./bazel-bin/isql

# 连接到指定主机和端口
./bazel-bin/isql -h 127.0.0.1 -p 18647

# 使用指定用户名和密码连接
./bazel-bin/isql -u admin -P password

# 启用加密连接
./bazel-bin/isql -e
```

## 功能特性

### 服务器端功能
- 支持自定义网络协议和MySQL协议
- 真实执行SQL命令（非模拟）
- 支持用户认证和权限检查
- 支持AES-256加密通信
- 支持TLS/SSL安全连接

### 客户端功能
- 支持连接到SQLCC服务器
- 支持用户认证
- 支持发送SQL查询命令
- 支持加密通信
- 支持TLS/SSL安全连接

## 网络协议

### 消息格式
```
+----------+----------+--------+-------+-------------+---------+
| 魔数(4) | 长度(4)  | 类型(4)| 标志(4)| 序列ID(4)  | 数据(N) |
+----------+----------+--------+-------+-------------+---------+
```

### 消息类型
- CONNECT: 客户端连接请求
- CONN_ACK: 连接确认响应
- AUTH: 认证请求
- AUTH_ACK: 认证确认响应
- QUERY: SQL查询请求
- QUERY_RESULT: 查询结果响应
- ERROR: 错误消息
- KEY_EXCHANGE: 密钥交换请求
- KEY_EXCHANGE_ACK: 密钥交换确认响应

## MySQL协议支持

服务器端同时支持自定义协议和MySQL协议，能够与标准MySQL客户端兼容。

## 安全特性

- 用户名/密码认证
- AES-256-CBC加密通信
- TLS/SSL安全连接
- HMAC-SHA256消息完整性验证
