⚠️ 覆盖率数据收集问题

问题诊断:
  • 测试成功执行，但覆盖率数据为空
  • Bazel 报告: "WARNING: There was no coverage found."
  • 编译器警告: "argument unused during compilation: '--coverage'"

根本原因

SQLCC 项目使用 LLVM/Clang 编译器，但 Bazel 默认使用 GCC 的覆盖率选项。这导致覆盖率工具链不匹配，无法收集覆盖率数据。

解决方案

建议的修复步骤:

方案 1: 修改 .bazelrc 配置（推荐）

# 在 .bazelrc 文件中添加以下配置 build --copt=-fprofile-instr-generate build --copt=-fcoverage-mapping build --linkopt=-fprofile-instr-generate build --llvm_covmap

方案 2: 使用自定义覆盖率配置

bazel coverage \ --instrument_test_targets \ --copt=-fprofile-instr-generate \ --copt=-fcoverage-mapping \ --linkopt=-fprofile-instr-generate \ --test_env=GCOV_PREFIX=$PWD/coverage \ --test_env=GCOV_PREFIX_STRIP=$PWD \ //tests/level1_foundation/...

方案 3: 修改 BUILD.bazel 文件

在测试的 BUILD.bazel 文件中添加 LLVM 覆盖率标志:

cc_test( name = "basic_test", srcs = ["basic_test.cpp"], copts = [ "-g", "-Wall", "-Wextra", "-fprofile-instr-generate", # LLVM 覆盖率编译 "-fcoverage-mapping", # 源码映射 ], linkopts = ["-fprofile-instr-generate"], # LLVM 覆盖率链接 deps = [...], tags = ["coverage", "level1", "unit"], )
