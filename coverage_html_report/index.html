🔍 报告说明

覆盖率指标说明

  • 函数覆盖率: 测试用例覆盖的函数比例
  • 行覆盖率: 测试执行的代码行比例
  • 区域覆盖率: 代码执行路径的覆盖程度
  • 分支覆盖率: 条件分支的测试覆盖情况

颜色编码

  • 🟢 绿色: 覆盖率 ≥ 80%
  • 🟡 黄色: 覆盖率 50-80%
  • 🔴 红色: 覆盖率 < 50%
