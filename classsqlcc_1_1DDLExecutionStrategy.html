检查用户是否有权限执行DDL语句。

该方法根据DDL语句的具体类型，分发到相应的权限检查函数。

参数

)

执行DDL语句的核心方法。

该方法根据DDL语句的具体类型（CREATE TABLE, DROP TABLE, ALTER TABLE, CREATE INDEX, DROP INDEX） 动态分发到相应的私有执行函数。

参数
stmt待执行的DDL语句的AST（抽象语法树）的唯一指针。所有权在此处转移。
context执行上下文，包含数据库管理器等信息。
返回
包含执行结果的ExecutionResult。
