详细描述

An RAII guard for safe, temporary, and consistent access to configuration.

This class is the primary client-facing tool for reading configuration. When created, it "locks in" the current configuration snapshot from the ConfigLifecycleManager. This snapshot is guaranteed to be stable for the lifetime of the accessor object, even if the global configuration is updated in the background. It is lightweight and designed to be created on the stack for short-lived operations.
