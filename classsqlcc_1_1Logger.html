详细描述

Thread-safe singleton logger class

This class provides a centralized logging facility for the SQLCC system. Features modern C++ patterns while maintaining backward compatibility.

Key improvements:

  • Smart pointers for memory safety
  • Thread-safe operations with mutex protection
  • Modern C++ data structures and algorithms
  • C++20 Modules support
