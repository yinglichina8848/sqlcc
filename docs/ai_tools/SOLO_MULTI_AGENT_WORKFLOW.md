# 单人多设备多Agent协作工作流

**版本**: 1.0
**日期**: 2026-02-07
**适用范围**: 单人使用多设备/多AI工具维护 SQLCC

---

## 1. 目标

在单人多设备、多Agent并行开发场景下，确保：
- 变更范围清晰
- 责任可追溯
- 冲突可控
- 合并可审计

---

## 2. 核心原则

- 一台设备同一时间只负责一个分支
- 不同设备不同时改同一分支
- 所有改动必须走 PR
- main 只接受 PR 合并

---

## 3. 设备与身份映射（建议）

- Mac Mini: `codex-ide`
- Ubuntu 笔记本: `opencode-developer`
- Win11 + WSL: `cline-developer`

> 若需要同时运行多个Agent，建议使用同一设备的不同分支，而不是同一分支。

---

## 4. 分支责任划分

- 文档类: `codex/docs-*`
- 功能类: `feature/*`
- 修复类: `fix/*`
- 重构类: `refactor/*`

---

## 5. 单人多Agent并行流程

1. 创建 Issue 或任务卡，写明范围与验收标准
2. 创建分支并绑定设备与身份
3. 完成改动并提交（含 Agent/Scope/Refs）
4. 创建 PR，填写自检清单
5. 自审后合并到 main

---

## 6. 冲突预防

- 同一文件由同一设备独占修改
- 若必须跨设备协作，拆分成两个分支
- 使用 PR 描述中明确“范围边界”

---

## 7. PR 自检清单（单人多AI）

- [ ] 目标单一（无范围漂移）
- [ ] 无无关文件修改
- [ ] 提交信息包含 Agent/Scope/Refs
- [ ] 文档引用路径存在
- [ ] TODO/TBD 已清理或注明原因
- [ ] 说明是否需要测试
- [ ] 下一步任务明确
