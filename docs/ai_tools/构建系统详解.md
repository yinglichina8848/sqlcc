# SQLCC Bazel构建系统详解

## 🏗️ Bazel构建系统概述

SQLCC使用Bazel作为构建系统，提供快速、可靠、可扩展的构建解决方案。

## 📁 构建配置文件结构

### 根目录构建配置 (BUILD.bazel)
```python
# SQLCC主构建配置
cc_binary(
    name = "sqlcc",
    srcs = ["src/main.cpp"],
    deps = [
        "//src/core:sqlcc_core",
        "//src/storage_engine:sqlcc_storage",
        "//src/sql_parser:sqlcc_parser",
        "//src/execution:sqlcc_execution",
        "//src/network:sqlcc_network",
        "//src/transaction_manager:sqlcc_transaction",
    ],
)
```

### 子模块构建配置
```python
# src/core/BUILD.bazel
cc_library(
    name = "sqlcc_core",
    srcs = [
        "config_manager.cpp",
        "error_handler.cpp",
        "database_manager.cpp",
    ],
    hdrs = ["//include/core:headers"],
    deps = ["//include/utils:types"],
)
```

## 🎯 构建目标类型

### 1. cc_library - 库目标
```python
cc_library(
    name = "my_library",
    srcs = ["implementation.cpp"],  # 实现文件
    hdrs = ["public_header.h"],     # 公共头文件
    deps = ["//other/package:dependency"],  # 依赖
)
```

### 2. cc_binary - 可执行目标
```python
cc_binary(
    name = "my_binary",
    srcs = ["main.cpp"],
    deps = [":my_library"],
)
```

### 3. cc_test - 测试目标
```python
cc_test(
    name = "my_test",
    srcs = ["my_test.cpp"],
    deps = [
        ":my_library",
        "@googletest//:gtest_main",
    ],
)
```

## 🔧 构建命令

### 基本构建
```bash
# 构建所有目标
bazel build //...

# 构建特定目标
bazel build //src/core:sqlcc_core

# 构建测试
bazel test //...
```

### 高级构建选项
```bash
# 带缓存的构建
bazel build --disk_cache=/tmp/bazel-cache //...

# 并行构建
bazel build --jobs=8 //...

# 生成覆盖率报告
bazel coverage //...
```

## 📊 依赖管理

### 内部依赖
```python
deps = [
    "//src/core:sqlcc_core",           # 相对路径依赖
    "//include/utils:types",           # 头文件库依赖
    ":local_target",                   # 同包内依赖
]
```

### 外部依赖
```python
deps = [
    "@googletest//:gtest",             # 外部仓库依赖
    "@com_google_absl//absl/strings",  # Abseil库
]
```

## 🎯 AI开发要点

### 理解构建系统的关键
1. **目标命名**: 使用描述性名称，如`sqlcc_core`而非`core`
2. **依赖声明**: 明确声明所有依赖，避免隐式依赖
3. **头文件管理**: 使用`hdrs`声明公共接口
4. **测试分离**: 测试目标与实现目标分离

### 修改构建配置的注意事项
1. **同步更新**: 修改源码后同步更新BUILD.bazel
2. **依赖检查**: 添加新依赖时检查是否必要
3. **测试验证**: 修改后运行构建验证
4. **缓存清理**: 重大变更时清理构建缓存
