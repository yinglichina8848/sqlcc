## 🏗️ BUILD.bazel 配置规范

### 基础配置模板

#### 最小化配置（用于简单测试）

```bazel
cc_test(
    name = "basic_test",
    srcs = ["basic_test.cpp"],
    deps = [
        "//include/...",
        "@com_google_googletest//:gtest_main",
        "@com_google_googletest//:gtest",
    ],
    tags = ["coverage", "level1"],
)
```

#### 标准配置（推荐）

```bazel
cc_test(
    name = "basic_test",
    srcs = ["basic_test.cpp"],
    copts = [
        "-g",  # 添加调试信息
        "-Wall",  # 启用所有警告
        "-Wextra",  # 启用额外警告
    ],
    deps = [
        "//include/...",
        "@com_google_googletest//:gtest_main",
        "@com_google_googletest//:gtest",
    ],
    tags = [
        "coverage",  # 覆盖率测试标签
        "level1",    # Level1测试标签
        "unit",      # 单元测试标签
    ],
    testonly = True,  # 仅用于测试
)
```

#### 完整配置（包含所有选项）

```bazel
cc_test(
    name = "basic_test",
    srcs = ["basic_test.cpp"],
    hdrs = ["basic_test.h"],
    copts = [
        "-g",
        "-Wall",
        "-Wextra",
        "-Werror",  # 将警告视为错误
        "-std=c++20",
    ],
    linkopts = [
        "-pthread",  # 链接pthread库
    ],
    defines = [
        "DEBUG",  # 调试宏定义
    ],
    deps = [
        "//include/...",
        "@com_google_googletest//:gtest_main",
        "@com_google_googletest//:gtest",
    ],
    tags = [
        "coverage",
        "level1",
        "unit",
        "manual",  # 手动测试
    ],
    testonly = True,
    timeout = "short",  # 测试超时设置: short/long/eternal
    size = "small",      # 测试规模: small/medium/large/enormous
    visibility = ["//visibility:public"],
)
```

### 配置规范说明

#### 1. 必需字段

| 字段 | 说明 | 示例 |
|------|------|------|
| `name` | 测试名称 | `"basic_test"` |
| `srcs` | 源文件列表 | `["basic_test.cpp"]` |
| `deps` | 依赖列表 | `["//include/..."]` |

#### 2. 推荐字段

| 字段 | 说明 | 推荐值 | 必填 |
|------|------|---------|------|
| `copts` | 编译选项 | `["-g", "-Wall", "-Wextra"]` | ✅ |
| `tags` | 测试标签 | `["coverage", "level1"]` | ✅ |
| `testonly` | 仅测试标志 | `True` | ✅ |
| `timeout` | 超时设置 | `"short"` | 推荐 |
| `size` | 测试规模 | `"small"` | 推荐 |

#### 3. 标签规范

**测试层次标签**:
- `level1`: Level1基础组件测试
- `level2`: Level2核心服务测试
- `level3`: Level3事务管理测试
- `level4`: Level4 SQL处理测试
- `level5`: Level5网络通信测试
- `level6`: Level6企业级特性测试
- `level7`: Level7高级集成测试

**测试类型标签**:
- `coverage`: 覆盖率测试
- `unit`: 单元测试
- `integration`: 集成测试
- `performance`: 性能测试
- `stress`: 压力测试
- `manual`: 手动测试

**模块标签**:
- `sql_parser`: SQL解析器测试
- `storage_engine`: 存储引擎测试
- `transaction`: 事务管理测试
- `network`: 网络通信测试
- `executor`: 执行器测试

**使用示例**:

## 🔧 编译和测试流程规范

### 1. 编译流程

#### 标准编译流程

```bash
# 1. 清理旧的构建输出
bazel clean

# 2. 配置Bazel缓存
bazel info output_base

# 3. 编译特定测试
bazel build //tests/level1_foundation/basic:basic_test

# 4. 编译所有测试
bazel build //tests/...

# 5. 验证编译结果
bazel test --nobuild //tests/...
```

#### 增量编译流程

```bash
# 只编译修改过的测试
bazel build //tests/level1_foundation/basic:basic_test --check_upToDate

# 只编译特定层次
bazel build //tests/level1_foundation/...

# 只编译失败的测试
bazel build //tests/... --check_upToDate
```

### 2. 测试流程

#### 标准测试流程

```bash
# 1. 运行特定测试
bazel test //tests/level1_foundation/basic:basic_test

# 2. 运行所有测试
bazel test //tests/...

# 3. 运行特定层次测试
bazel test //tests/level1_foundation/...

# 4. 运行带标签的测试
bazel test //tests/... --test_tag_filters=coverage

# 5. 运行失败的测试
bazel test //tests/... --test_tag_filters=coverage --cache_test_results=no
```

#### 覆盖率测试流程

```bash
# 1. 运行覆盖率测试（推荐）
bazel coverage \
    //tests/level1_foundation/... \
    //tests/level2_core_services/... \
    --instrumentation_filter="//include/..." \
    --combined_report=lcov

# 2. 运行Level1覆盖率测试
bazel coverage \
    //tests/level1_foundation/... \
    --instrumentation_filter="//include/..." \
    --combined_report=lcov \
    --output_path=tests/test_output/coverage/level1

# 3. 运行Level2覆盖率测试
bazel coverage \
    //tests/level2_core_services/... \
    //tests/level2_storage_engine/... \
    --instrumentation_filter="//include/..." \
    --combined_report=lcov \
    --output_path=tests/test_output/coverage/level2

# 4. 生成HTML报告
genhtml bazel-out/_coverage/_coverage_report.dat \
    -o tests/test_output/coverage/reports/html/

# 5. 查看覆盖率统计
lcov --summary bazel-out/_coverage/_coverage_report.dat
```

### 3. 输出目录管理

#### 创建输出目录

```bash
# 创建测试输出目录
mkdir -p tests/test_output/{build,coverage,logs,results}

# 创建覆盖率子目录
mkdir -p tests/test_output/coverage/{raw,reports,latest}

# 创建报告子目录
mkdir -p tests/test_output/coverage/reports/{html,text,json}

# 创建日志子目录
mkdir -p tests/test_output/logs/{build,test,coverage}

# 创建符号链接（最新报告）
ln -sfn $(date +%Y%m%d_%H%M%S) tests/test_output/coverage/reports/latest
```

#### 清理输出目录

```bash
# 清理旧的覆盖率数据
find tests/test_output/coverage/raw -name "*.profraw" -mtime +7 -delete

# 清理旧的报告
find tests/test_output/coverage/reports -type d -mtime +30 -delete

# 清理旧的日志
find tests/test_output/logs -name "*.log" -mtime +30 -delete

# 保留最近3天的数据
find tests/test_output -type f -mtime +3 -delete
```

**示例**:

### 统一测试脚本模板

#### 基础测试脚本模板

```bash
#!/bin/bash
#
# SQLCC Level1 基础测试脚本

echo "  SQLCC Level1 基础测试"
echo "========================================="
```

#### 覆盖率测试脚本模板

```bash
#!/bin/bash
#
# SQLCC Level1-Level2 覆盖率测试脚本
#

set -e

PROJECT_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
cd "${PROJECT_ROOT}"

# 配置输出目录
OUTPUT_DIR="${PROJECT_ROOT}/tests/test_output"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
COVERAGE_DIR="${OUTPUT_DIR}/coverage"
REPORT_DIR="${COVERAGE_DIR}/reports/${TIMESTAMP}"

# 创建输出目录
mkdir -p "${REPORT_DIR}/html"
mkdir -p "${REPORT_DIR}/text"
mkdir -p "${REPORT_DIR}/json"
mkdir -p "${COVERAGE_DIR}/raw"
mkdir -p "${COVERAGE_DIR}/reports/latest"

echo "========================================="
echo "  SQLCC Level1-Level2 覆盖率测试"
echo "========================================="
echo "开始时间: $(date)"
echo ""

# 运行覆盖率测试
echo "运行覆盖率测试..."
bazel coverage \
    //tests/level1_foundation/... \
    //tests/level2_core_services/... \
    --instrumentation_filter="//include/..." \
    --combined_report=lcov \
    2>&1 | tee "${COVERAGE_DIR}/logs/coverage_${TIMESTAMP}.log"

# 复制覆盖率报告
if [ -f "bazel-out/_coverage/_coverage_report.dat" ]; then
    cp bazel-out/_coverage/_coverage_report.dat "${REPORT_DIR}/coverage_report.dat"
    
    # 生成文本报告
    if command -v lcov &> /dev/null; then
        lcov --summary "${REPORT_DIR}/coverage_report.dat" \
            > "${REPORT_DIR}/text/coverage_summary.txt"
        
        lcov --list "${REPORT_DIR}/coverage_report.dat" \
            > "${REPORT_DIR}/text/coverage_details.txt"
        
        lcov --list "${REPORT_DIR}/coverage_report.dat" | \
            awk '{print $5}' | sort -n | head -10 \
            > "${REPORT_DIR}/text/coverage_lowest.txt"
    fi
    
    # 生成HTML报告
    if command -v genhtml &> /dev/null; then
        genhtml --ignore-errors inconsistent,corrupt \
            "${REPORT_DIR}/coverage_report.dat" \
            -o "${REPORT_DIR}/html" \
            --title "Level1-Level2 Coverage Report ${TIMESTAMP}"
    fi
else
    echo "错误: 未找到覆盖率报告文件"
    exit 1
fi

# 创建最新报告链接
rm -f "${COVERAGE_DIR}/reports/latest"
ln -s "${TIMESTAMP}" "${COVERAGE_DIR}/reports/latest"

echo ""
echo "========================================="
echo "覆盖率测试完成!"
echo "========================================="
echo "报告位置: ${REPORT_DIR}/"
echo "最新链接: ${COVERAGE_DIR}/reports/latest/"
echo ""
echo "完成时间: $(date)"
echo "========================================="
```

## ✅ BUILD.bazel 配置统一标准

### 统一配置检查清单

每个测试的BUILD.bazel文件必须包含：

- [ ] `name`: 测试名称
- [ ] `srcs`: 源文件列表
- [ ] `deps`: 依赖列表
- [ ] `copts`: 编译选项（推荐包含 `-g`, `-Wall`, `-Wextra`）
- [ ] `tags`: 测试标签（必须包含 `coverage` 和层次标签）
- [ ] `testonly`: 测试标志

### 统一修复要求

#### 必须添加的配置

```bazel
# 所有测试都必须添加
copts = [
    "-g",      # 调试信息
    "-Wall",   # 所有警告
    "-Wextra", # 额外警告
],

tags = [
    "coverage",  # 覆盖率测试标签
    "levelX",   # 层次标签（level1-level7）
    "unit",     # 测试类型标签（unit/integration/performance/stress/manual）
],
```

#### 可选的配置

```bazel
# 可选配置
timeout = "short",  # 测试超时设置
size = "small",      # 测试规模
defines = ["DEBUG"], # 宏定义
linkopts = ["-pthread"], # 链接选项
```

## 📝 配置修复流程

### 修复步骤

1. **识别需要修复的BUILD.bazel文件**
   ```bash
   find tests/ -name "BUILD.bazel" -exec grep -L "coverage" {} \;
   ```

2. **备份原始BUILD.bazel**
   ```bash
   find tests/ -name "BUILD.bazel" -exec cp {} {}.backup \;
   ```

3. **修复BUILD.bazel配置**
   - 添加缺失的 `copts` 配置
   - 添加缺失的 `tags` 配置
   - 确保测试依赖正确

4. **验证修复结果**
   ```bash
   # 验证编译
   bazel build //tests/...
   
   # 验证测试
   bazel test //tests/... --nobuild
   ```

5. **生成覆盖率报告**
   ```bash
   bazel coverage //tests/... \
       --instrumentation_filter="//include/..." \
       --combined_report=lcov
   ```

## 🎯 质量保证

### BUILD.bazel 质量检查

#### 自动检查脚本

```bash
#!/bin/bash
# 检查BUILD.bazel配置质量

find tests/ -name "BUILD.bazel" | while read file; do
    echo "检查: $file"
    
    # 检查是否包含coverage标签
    if grep -q "coverage" "$file"; then
        echo "  ✅ 包含coverage标签"
    else
        echo "  ❌ 缺少coverage标签"
    fi
    
    # 检查是否包含copts
    if grep -q "copts" "$file"; then
        echo "  ✅ 包含copts配置"
    else
        echo "  ⚠️  缺少copts配置（推荐）"
    fi
    
    # 检查是否包含testonly
    if grep -q "testonly" "$file"; then
        echo "  ✅ 包含testonly标志"
    else
        echo "  ⚠️  缺少testonly标志（推荐）"
    fi
    
    echo ""
done
```
