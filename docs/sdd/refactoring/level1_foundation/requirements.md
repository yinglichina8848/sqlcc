## 1. 概述

### 1.1 项目背景

Level 1 Foundation 是 SQLCC 项目的基础层组件，包含异常处理、类型系统、配置管理、日志系统、工具类和基础测试。该层不依赖任何上层模块，为整个系统提供基础设施支持。

### 1.2 重构目标

| 属性 | 值 |

| ID | REQ-001 |
| 优先级 | P0 |
| 状态 | 已完成 |

#### 描述

**当** 系统需要验证异常处理机制的正确性,
**我想要** 完整的异常类单元测试,
**以便于** 确保异常传播、捕获和处理符合预期。

#### 接受标准

- [x] 测试所有异常类的构造函数（BaseException, IOException, SpecificException）

- [x] 测试异常嵌套和继承关系
- [x] 测试边界条件（空消息、超长消息、特殊字符）

| 条件 | 处理方式 |
|------|---------|
| 空异常消息 | 返回空字符串 |
| 超长消息 (>4KB) | 正常处理，无截断 |
| 嵌套异常 | 正确传递堆栈信息 |
