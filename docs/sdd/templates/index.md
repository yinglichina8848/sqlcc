## 模板详情

### 1. 需求模板 (requirements_template.md)

**用途**: 定义功能需求、非功能需求

**包含内容**:
- EARS 格式需求定义
- 测试用例模板
- 验收标准

**使用阶段**: `spec-requirements`

### 2. 设计模板 (design_template.md)

**用途**: 描述系统架构、接口设计

**包含内容**:
- 架构决策记录 (ADR)
- Mermaid 类图/序列图
- BUILD 配置示例

**使用阶段**: `spec-design`

### 3. 任务模板 (tasks_template.md)

**用途**: 分解任务、跟踪进度

**包含内容**:
- 任务清单表格
- 依赖图 (Mermaid)
- 燃尽图数据

**使用阶段**: `spec-tasks`

### 4. 确认模板 (verification_template.md) ⭐

**用途**: 验证完成状态、版本发布

**包含内容**:
- 编译验证
- 测试验证
- 代码质量检查
- 文档完整性检查
- 版本发布确认
- 分支冻结状态

**使用阶段**: `spec-verification` (impl 之后)

### 5. 多Agent协作模板 (multi_agent_collaboration_template.md) ⭐⭐

**用途**: 多Agent并行开发协调

**包含内容**:
- Agent角色定义 (Master/Developer/Tester/Documenter/Reviewer)
- 任务状态机 (OPEN → CLAIMED → WIP → DONE → FROZEN)
- 任务认领/进度更新/阻塞通知消息协议
- 并行度配置和资源冲突检测
- 任务看板和燃尽图
- 故障处理和任务恢复

**使用阶段**: `spec-tasks` + `spec-impl` (多Agent并行开发时)
