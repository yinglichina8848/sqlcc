## 改进流程

### 流程说明

```
1. Gemini 提出 Issue (本文档)
   ↓
2. 高小原 创建任务
   ↓
3. Claude/OpenCode 修复 Issue
   ↓
4. Gemini 评审修复结果
   ↓
5. 评分 >= 80%? → 是 → 关闭 Issue
   ↓ 否
6. 返回步骤 2
```

### 评分标准

| 分数 | 说明 |
|------|------|
| 100 | 完美，无需改进 |
| 90 | 优秀，只需小改进 |
| 80 | 良好，达到合并标准 |
| 70 | 一般，需要改进 |
| 60 | 及格，需要大改进 |
| <60 | 不及格，需要重做 |
