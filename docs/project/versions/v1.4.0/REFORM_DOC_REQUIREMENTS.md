# SQLCC v1.4.x 文档重构需求（编译基线优先）

**版本**: v1.4.x
**创建日期**: 2026-02-07
**负责人**: Codex（AI-IDE）

---

## 1. 背景与目标

v1.4.x 阶段的核心目标是：
- **建立可编译、可运行的基线版本**
- **必要的重构与解耦，消除组件循环依赖**
- **不引入新功能（功能性补充放入 v1.5.x）**

文档侧必须反映该战略目标，避免“设计文档宣称功能已存在但实际未实现”的偏差。

---

## 2. 范围与边界

**范围（v1.4.x）**
- 编译基线：修复构建与依赖问题
- 架构解耦：组件独立，移除循环依赖
- 文档对齐：设计文档标注“现状/规划”
- 索引修复：文档索引与链接完整可用
- TODO/计划统一汇总，作为重构需求清单

**不在范围（v1.4.x）**
- 新功能开发
- 功能性补全
- 业务扩展/性能增强

> 新功能统一进入 **v1.5.x** 规划。

---

## 3. 当前发现的问题（摘要）

### 3.1 文档索引/链接大量失效
- 扫描结果：**发现 685 处断链**（docs/ 目录内）
- 典型高频断链来源：
  - `docs/index.md`
  - `docs/design/设计文档总览.md`
  - `docs/README.en.md`

### 3.2 设计文档与现状不一致
- 部分设计文档未标注“现状 vs 规划”，导致读者误判功能已实现。
- 需要**统一标注**：
  - “现状（已实现）”
  - “规划（未实现）”

### 3.3 v1.4.0 计划/TODO 未统一
- v1.4.0 目录内存在 TODO 与未完成事项分散记录：
  - `CORE_STORAGE_DEPENDENCY_ANALYSIS.md`
  - `ISSUE_001.md`
  - `GEMINI_REVIEW_REPORT.md`
  - `GEMINI_STRICT_REVIEW.md`
