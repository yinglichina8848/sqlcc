## 🔧 技术问题与解决方案

### 1. Include路径配置问题
#### 问题描述:
Bazel的include路径配置需要正确设置`-I`编译选项。

#### 解决方案:
```bazel
cc_library(
    name = "logger",
    # ... 其他配置
    copts = [
        "-Iinclude",  # 设置include根目录
        "-std=c++20",
        # ... 其他选项
    ],
)
```

### 2. 标签引用规范化
#### 问题描述:
BUILD.bazel文件中的标签引用需要使用标准格式。

#### 解决方案:
```bazel
# 错误的写法
hdrs = ["../../include/utils/logger.h"]

# 正确的写法
hdrs = ["//include/utils:logger.h"]
```

### 3. 参数重复问题
#### 问题描述:
同一个参数在BUILD.bazel中出现多次导致解析错误。

#### 解决方案:
- 检查BUILD.bazel文件语法
- 合并重复的参数定义
