### 修复策略总结

#### 头文件路径问题
- **问题模式**: 源码文件直接引用其他头文件时使用相对路径
- **解决方法**: 使用完整的包路径引用，如 `sql_parser/ast_nodes.h`

#### 依赖声明问题
- **问题模式**: 编译时发现缺失的头文件依赖
- **解决方法**: 分析编译错误，添加对应的 Bazel 依赖声明

#### 编译选项配置
- **问题模式**: 头文件搜索路径不正确
- **解决方法**: 添加 `-Iinclude` 编译选项

## 技术经验总结

### 1. 依赖关系的重要性
- 正确识别和声明包间依赖是构建成功的关键
- 缺失依赖会导致编译失败，过度依赖会增加构建时间

### 2. 头文件路径管理
- 使用一致的头文件引用方式，避免相对路径问题
- 正确配置编译器的头文件搜索路径

### 3. 增量修复策略
- 从底层包开始修复，建立稳定的基础
- 逐层验证，确保每层修复都是正确的
