## 💡 经验教训

### 技术经验

1. **BUILD系统维护**:
   - 大型项目的BUILD文件需要定期维护
   - 头文件路径问题往往牵一发而动全身
   - 符号链接是解决路径问题的有效手段

2. **头文件组织**:
   - 重复定义的头文件会导致编译错误
   - `include/` 和 `src/` 目录应该有明确分工
   - 建议使用Bazel的 `includes` 属性管理包含路径

### 流程经验

1. **问题排查**:
   - 从错误信息开始，逐步追溯依赖链
   - 记录每个修复，便于回溯
   - 对于复杂项目，BUILD问题可能需要系统性解决

2. **测试策略**:
   - 优先测试不依赖复杂组件的简单模块
   - 对于依赖复杂的模块，考虑使用Mock隔离
   - 分阶段验证，先确保编译通过再运行测试
