## 🔧 遇到的技术问题

### 1. SQL Parser AST模块架构问题
**问题**: AST模块存在双重定义
- `expression.h` 定义了一套表达式类（ast命名空间）
- `ast_expression_nodes.h/cpp` 定义了另一套（sql_parser命名空间）
- 导致大量编译错误和命名冲突

**影响**: 无法编译Level2和Level3测试（依赖SQL Parser）

### 2. 测试代码API不兼容
**问题**: 测试代码使用已删除的API
- `DiskManager::SetSimulateReadFailure()` 方法不存在
- `ConfigManager` 构造函数变为私有
- 依赖已删除的 `include/` 目录

**影响**: Level2测试无法编译通过

### 3. BUILD.bazel配置问题
**问题**: 测试依赖配置不正确
- 缺少必要的实现文件（如`ast_dcl_statements.cpp`）
- include路径指向已删除的目录
- 依赖声明不完整

**影响**: 链接错误
