## 💡 经验教训

### 技术经验

1. **BUILD系统维护**:
   - 大型项目的BUILD文件需要定期维护
   - 依赖关系变更时需要同步更新所有相关BUILD文件
   - 重构时要检查所有引用点

2. **测试框架搭建**:
   - 在编写测试之前，先确保目标模块能够编译
   - Mock类应该基于实际接口设计
   - 分阶段验证，先编译通过后运行测试

### 流程经验

1. **问题排查**:
   - 从错误信息开始，逐步追溯依赖链
   - 记录每个修复，便于回溯
   - 保持耐心，大型项目的问题往往错综复杂
