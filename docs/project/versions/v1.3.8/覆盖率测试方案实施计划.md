## 📋 执行计划

### Phase 1: 分析和诊断（已完成）

#### 1.1 问题识别

**v1.3.7版本问题**:
- ❌ 覆盖率工具配置错误
- ❌ 所有覆盖率指标为0 (FNF:0, FNH:0, LH:0, LF:0)
- ❌ 编译选项 `--coverage` 未被识别

**v1.3.8版本问题**:
- ⚠️ 真实覆盖率27.3%（估算）
- ⚠️ SQL解析器0%覆盖率
- ⚠️ 执行引擎0%覆盖率
- ⚠️ 核心组件0%覆盖率

#### 1.2 根本原因分析

**覆盖率数据为0的原因**:
1. **错误的编译选项**: 使用 `--coverage` 而非LLVM覆盖率选项
2. **缺少覆盖率配置**: `.bazelrc` 中未配置 `--config=coverage`
3. **手动环境变量**: 手动设置 `LLVM_PROFILE_FILE` 容易出错

**正确的方法**:
```bash
# 错误的选项
bazel test --copt=--coverage ...

# 正确的选项
bazel test --config=coverage \
    --combined_report=lcov \
    --instrumentation_filter="//include/..."
```

### Phase 2: 解决方案设计（已完成）

#### 2.1 方案对比

| 方案 | 优势 | 劣势 | 推荐度 |
|------|------|------|--------|
| **Bazel内置Coverage** | 自动化、简单、可靠 | 依赖Bazel版本 | ⭐⭐⭐⭐⭐ |
| **手动LLVM工具链** | 灵活、细粒度控制 | 复杂、易出错 | ⭐⭐⭐ |
| **模块分别测试** | 便于分析对比 | 工作量大 | ⭐⭐⭐⭐ |

**推荐方案**: Bazel内置Coverage功能

#### 2.2 实施方案

**方案1: 使用Bazel内置Coverage（主方案）**

##### 配置步骤
1. 配置 `.bazelrc` 文件
2. 运行 `bazel coverage` 命令
3. 生成覆盖率报告

##### 优势
- Bazel自动处理覆盖率数据收集
- 无需手动设置环境变量
- 自动合并所有测试的覆盖率数据
- 支持增量覆盖率分析

##### 命令示例
```bash
# 运行Level1-Level2测试
bazel coverage \
    //tests/level1_foundation/... \
    //tests/level2_core_services/... \
    --instrumentation_filter="//include/..." \
    --combined_report=lcov

# 生成HTML报告
genhtml bazel-out/_coverage/_coverage_report.dat -o coverage_html/
```

**方案2: 手动LLVM工具链（备用方案）**

##### 适用场景
- 需要更细粒度的控制
- 需要分析特定的二进制文件
- Bazel配置有冲突时

##### 实施步骤
1. 手动设置编译选项
2. 运行测试并收集.profraw文件
3. 合并覆盖率数据
4. 生成覆盖率报告

##### 命令示例
```bash
# 设置编译选项
bazel build --copt=-fprofile-instr-generate --copt=-fcoverage-mapping ...

# 运行测试
export LLVM_PROFILE_FILE="$COVERAGE_DIR/test_%p.profraw"
bazel run //tests/...

# 合并数据
llvm-profdata-20 merge $COVERAGE_DIR/*.profraw -o $COVERAGE_DIR/merged.profdata

# 生成报告
llvm-cov-18 report --instr-profile=$COVERAGE_DIR/merged.profdata ...
```

## 📝 注意事项

### 1. 编译器版本

确保使用Clang 18+版本：
```bash
clang --version
```

### 2. Bazel版本

确保使用Bazel 8.5.0+版本：
```bash
bazel version
```

### 3. 磁盘空间

覆盖率数据可能占用较大空间：
```bash
df -h
```

### 4. 测试时间

完整测试可能需要较长时间：
```bash
# 快速测试（仅Level1）
bazel coverage //tests/level1_foundation/...

# 完整测试（Level1+Level2）
bazel coverage //tests/level1_foundation/... //tests/level2_core_services/...
```
