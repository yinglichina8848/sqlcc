## 🔄 后续建议

### 1. 定期清理编译产物

建议创建定期清理脚本，自动删除编译和测试中间目录：

```bash
#!/bin/bash
# scripts/cleanup_build_artifacts.sh

# 删除覆盖率中间目录
rm -rf coverage_data coverage_output coverage_report coverage_results_real

# 删除Bazel缓存
bazel clean

echo "编译产物清理完成"
```

### 2. 规范化test_results目录

建议建立test_results目录的子目录结构：

```
test_results/
├── benchmark/              # 基准测试结果
├── coverage/               # 覆盖率报告
├── integration/            # 集成测试结果
└── performance/            # 性能测试结果
```

### 3. 定期清理备份目录

建议定期清理过期的备份：

```bash
#!/bin/bash
# scripts/cleanup_backups.sh

# 保留最近3个月的备份
find backups/ -type d -name "include_backup_*" -mtime +90 -delete
find backups/ -type d -name "uncertain_files_*" -mtime +90 -delete

echo "过期备份清理完成"
```

如果需要恢复备份的文件：


### 2. 重新生成覆盖率报告

如果需要重新生成覆盖率报告：

```bash
# 运行测试并生成覆盖率

# 生成HTML报告
genhtml coverage.info -o coverage_report
```

确保 `.gitignore` 包含以下内容：
