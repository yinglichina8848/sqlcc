   - `level6_enterprise/` 和 `level6_integration/` - 同为Level 6

2. **分类不明确**
   - `sql_parser/` - 不明确属于哪个Level
   - `temporary/` - 临时测试，应明确用途
   - `unit/` - 单元测试，应与Level测试区分

#### 建议的改进

```bash
# 1. 合并level2目录
mv tests/level2_storage_engine/* tests/level2_core_services/
rmdir tests/level2_storage_engine

# 2. 合并level6目录
mv tests/level6_enterprise/* tests/level6_integration/
rmdir tests/level6_enterprise

# 3. 明确分类
# sql_parser/ -> tests/level4_sql_processing/sql_parser/
# temporary/ -> 保留，用于临时测试
# unit/ -> 合并到对应的Level目录
```
