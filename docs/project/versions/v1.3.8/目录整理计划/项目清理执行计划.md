## 🚀 执行命令（一键执行）

将以下命令复制到终端执行：

```bash
#!/bin/bash

echo "=== SQLCC 项目清理开始 ==="

# 1. 删除废弃目录
echo "步骤1: 删除废弃目录..."
rm -rf src/_deprecated_storage_headers/
rm -rf src/storage/
rm -rf tools/__pycache__

# 2. 移动备份目录
echo "步骤2: 移动备份目录..."
mv src/core_backup_20260121_001034 backups/ 2>/dev/null || echo "core_backup已移动或不存在"

# 3. 移动临时测试目录
echo "步骤3: 移动临时测试目录..."
mv test_dir/* tests/temporary/ 2>/dev/null || echo "test_dir已移动或不存在"
rmdir test_dir 2>/dev/null || echo "test_dir已删除或不存在"

# 4. 移动测试报告
echo "步骤4: 移动测试报告..."
mv test_reports/* test_results/ 2>/dev/null || echo "test_reports已移动或不存在"
rmdir test_reports 2>/dev/null || echo "test_reports已删除或不存在"

# 5. 合并level2测试目录
echo "步骤5: 合并level2测试目录..."
mv tests/level2_storage_engine/* tests/level2_core_services/ 2>/dev/null || echo "level2_storage_engine已合并或不存在"
rmdir tests/level2_storage_engine 2>/dev/null || echo "level2_storage_engine已删除或不存在"

# 6. 合并level6测试目录
echo "步骤6: 合并level6测试目录..."
mv tests/level6_enterprise/* tests/level6_integration/ 2>/dev/null || echo "level6_enterprise已合并或不存在"
rmdir tests/level6_enterprise 2>/dev/null || echo "level6_enterprise已删除或不存在"

# 7. 清理临时文件
echo "步骤7: 清理临时文件..."
find . -name "*.o" -type f -delete
find . -name "*.a" -type f -delete
find . -name "*.so" -type f -delete
find . -name "*.gcov" -type f -delete
find . -name "*.gcda" -type f -delete
find . -name "*.gcno" -type f -delete
find . -name "coverage.info" -type f -delete
find . -name "*_log.txt" -type f -delete
find . -name "*_log.md" -type f -delete
find . -type d -name "__pycache__" -exec rm -rf {} + 2>/dev/null
find . -name "*.pyc" -type f -delete
find . -name "*.pyo" -type f -delete

echo "=== SQLCC 项目清理完成 ==="

# 验证结果
echo ""
echo "=== 验证结果 ==="
echo "src目录结构："
ls -d src/*/ | grep -v bazel
echo ""
echo "tests目录结构："
ls -d tests/*/
echo ""
echo "backups目录："
ls backups/
echo ""
echo "test_results目录："
ls test_results/
```

## 📝 注意事项

1. **备份重要数据**: 在执行清理前，建议先备份重要数据
2. **检查Git状态**: 清理前检查Git状态，确保没有未提交的重要更改

4. **验证结果**: 清理后使用验证清单确认清理效果
5. **提交更改**: 清理完成后，提交Git更改
