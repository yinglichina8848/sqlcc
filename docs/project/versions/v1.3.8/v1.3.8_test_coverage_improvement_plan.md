### Phase 1: 紧急修复 (1-2周)

#### 1.1 修复编译环境问题

**问题**: `common_ast` target 未定义
```
ERROR: no such target '//src/sql_parser:common_ast': 
target 'common_ast' not declared in package 'src/sql_parser'
```

**解决方案**:
在 `src/sql_parser/BUILD.bazel` 中添加:
```bazel
cc_library(
    name = "common_ast",
    srcs = [
        "data_types.cpp",
        "datetime.cpp",
        "decimal.cpp",
        "set_operation.cpp",
    ],
    hdrs = [
        "data_types.h",
        "datetime.h",
        "decimal.h",
        "set_operation.h",
        "operator_kind.h",
    ],
    visibility = ["//visibility:public"],
)
```

### Phase 3: 质量提升 (4-8周)

#### 3.1 建立真实覆盖率收集

**工具链**:
```bash
# 编译时插桩
bazel coverage //tests/... --config=coverage

# 生成报告
llvm-cov export -format=lcov -instr-profile=merged.profdata binary > coverage.lcov
genhtml coverage.lcov -o coverage_html/
```

**CI/CD 集成**:
```yaml
# .github/workflows/coverage.yml
coverage:
  runs-on: ubuntu-latest
  steps:
    - uses: actions/checkout@v2
    - name: Collect Coverage
      run: bazel coverage //tests/...
    - name: Upload Report
      uses: codecov/codecov-action@v1
```

#### 3.2 质量门禁

**阈值设置**:
