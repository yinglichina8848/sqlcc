## 📈 各模块详细特性说明

### 1. SQL-92 执行引擎模块

根据 [v1.3.4 RELEASE_NOTES](../../../releases/RELEASE_NOTES_v1.3.4.md) 的实际实现：

#### 核心特性
- **SetOperationExecutor**: UNION/INTERSECT/EXCEPT 集合操作真实执行
- **SubqueryExecutor**: 嵌套子查询和相关子查询真实执行
- **WindowFunctionExecutor**: ROW_NUMBER, RANK, SUM, AVG等窗口函数
- **RecursiveQueryExecutor**: WITH RECURSIVE 递归查询支持
- **CTEExecutor**: 公用表表达式核心执行逻辑

#### 企业特性
- **真实执行**: 所有SQL-92特性均为真实执行，非模拟
- **性能优化**: 查询计划优化和执行策略选择
- **错误处理**: 完善的语法和语义错误检测

### 2. SQL 解析器模块 (v1.3.8 ParserNew架构)

根据 [v1.3.8 RELEASE_NOTES](../../../releases/RELEASE_NOTES_v1.3.8.md) 的模块化重构：

#### 核心特性 (5个子库模块化)
- **ast子库**: AST基础库，包含AST节点定义和数据类型管理 (5个文件)
- **lexer子库**: 词法分析器库，处理token解析 (2个文件)
- **parser子库**: SQL语法解析核心库，构建AST (11个文件)
- **window子库**: 窗口函数处理库 (2个文件)
- **json子库**: JSON数据处理库 (2个文件)

#### SQL-92兼容性
- **完整语法支持**: 100% SQL-92标准语法解析
- **语义检查**: 完整的语义分析和类型检查
- **错误恢复**: 智能错误恢复和建议修复

### 3. 存储引擎模块

#### 核心特性
- **8KB定长页管理**: 标准数据库页式存储
- **V3分片缓冲池**: Sharded Buffer Pool架构，高并发支持
- **B+树索引**: 支持点查询和范围查询
- **WAL日志**: 预写日志保证ACID特性

#### SQL-92存储支持
- **数据类型完整实现**: 所有SQL-92标准数据类型
- **约束实现**: PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK, NOT NULL
- **索引优化**: 自动索引选择和查询优化

### 4. 事务管理器模块

#### 核心特性
- **ACID保证**: 原子性、一致性、隔离性、持久性
- **两阶段锁**: 2PL并发控制
- **死锁检测**: 自动死锁检测和解决
- **崩溃恢复**: 基于WAL的崩溃恢复

#### SQL-92事务支持
- **隔离级别**: READ UNCOMMITTED, READ COMMITTED, REPEATABLE READ, SERIALIZABLE
- **保存点管理**: SAVEPOINT, RELEASE SAVEPOINT, ROLLBACK TO SAVEPOINT
- **事务状态**: 完整的事务状态管理
