## 三、备选方案 (如果clang-18安装失败)

修改 `.bazelrc` 使用GCC：

```bash
# 创建本地覆盖配置
cat > .bazelrc.user << 'EOF'
# 使用GCC替代clang-18
build --action_env=CC=gcc
build --action_env=CXX=g++
build --cxxopt=-std=c++17
build --cxxopt=-stdlib=libstdc++
build --linkopt=-stdlib=libstdc++
# 移除libc++abi依赖
build --linkopt=-lstdc++
EOF
```

然后重新构建：
```bash
bazel clean --expunge
bazel build //src/logger:logger
bazel test //tests/unit:logger_test
```
