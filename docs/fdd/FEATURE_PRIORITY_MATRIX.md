# SQLCC 功能优先级矩阵（FDD）

**版本**: v1.0  
**日期**: 2026-02-06  
**说明**: 功能点优先级与迭代计划草案。

---

## 1. 优先级定义

- P0: 核心业务阻塞项
- P1: 核心能力提升
- P2: 增强/优化项

---

## 2. 优先级矩阵（确认版）

| 功能域 | 功能点 | 优先级 | 迭代 | 备注 |
|---|---|---|---|---|
| SQL 处理 | SQL Parser 语法解析 | P0 | 迭代1 | 稳定性优先 |
| SQL 处理 | AST 构建与校验 | P0 | 迭代1 | 依赖 Parser 核心能力 |
| 存储引擎 | 缓冲池管理 | P0 | 迭代1 | 关联 IBufferPool |
| 存储引擎 | 磁盘管理 | P0 | 迭代1 | 核心持久化能力 |
| 事务管理 | 事务生命周期 | P0 | 迭代1 | 一致性保障 |
| 事务管理 | WAL 日志 | P0 | 迭代1 | 可靠性基础 |
| 执行引擎 | 统一执行器 | P1 | 迭代1 | 基础执行链路 |
| 存储引擎 | B+树索引 | P1 | 迭代2 | 依赖存储基础能力 |
| 安全与权限 | RBAC 权限模型 | P1 | 迭代2 | 企业级能力 |
| 网络与协议 | 连接/会话管理 | P1 | 迭代2 | 可用性与安全 |
| 监控与运维 | 慢查询分析 | P2 | 迭代3 | 可延后 |
| 工具链与构建 | Bazel 构建体系 | P2 | 迭代3 | 持续改进 |

---

## 3. 迭代说明

- 迭代1: 核心链路可用 + 可验证
- 迭代2: 核心能力增强 + 性能稳定
- 迭代3: 运维与高级特性完善

---

## 4. 确认说明

- 本矩阵已按“性能/稳定优先”策略确认
