## 🔍 核心问题分析

### 1. 严重重叠问题

#### Unit vs Components重叠
```
问题: unit/executor/ 与 components/executor/ 测试相同功能
影响: 维护困难，测试结果不一致
解决方案: 合并到unit/，移除components/executor/
```

#### 多个SQL测试目录
```
问题: sql/, sql_executor/, sql_parser/ 功能重叠
影响: 测试分散，难以管理
解决方案: 统一到sql/下的子目录
```

#### 网络测试多处分布
```
问题: unit/network/, components/network/, integration/网络测试
影响: 网络测试分散在多处
解决方案: 统一到network/目录
```

### 2. 命名不规范问题

#### 文件命名混乱
- `test_sql_executor.cpp` vs `sql_executor_test.cpp`
- `test_task_executor.cpp` vs `task_executor_test.cpp`
- 建议统一使用: `{功能}_{类型}_test.cpp`

#### 目录命名不一致
- `sql_executor/` vs `sql-executor/`
- `storage_engine/` vs `storage-engine/`
- 建议使用snake_case统一命名

### 3. 结构不统一问题

#### BUILD文件格式不一致
- 有些用`BUILD`，有些用`BUILD.bazel`
- 建议统一使用`BUILD.bazel`

#### 目录深度不一致
- 有些目录只有一层: `unit/basic/`
- 有些目录有多层: `performance/basic/`
- 需要统一目录结构

### 4. 内容缺失问题

#### 空目录过多
- stubs/, advanced_sql/, client_server/ 为空
- 建议填充内容或移除

#### 测试覆盖不全
- security/ 只有内存安全测试
- 缺少加密安全、访问控制等测试

### 2. 具体整合方案

#### 方案A: 激进整合 (推荐)
1. **移除重叠目录**:
   - 删除 `components/` (合并到 `unit/`)
   - 删除 `sql_executor/` (合并到 `integration/sql/`)
   - 删除 `sql_parser/` (合并到 `unit/parser/`)

2. **重组现有测试**:
   - 将所有单元测试集中到 `unit/`
   - 将所有集成测试集中到 `integration/`
   - 保留 `performance/`, `security/`, `demo/`

3. **清理空目录**:
   - 删除 `stubs/`, `advanced_sql/`, `client_server/`
   - 填充或重定向有用内容

#### 方案B: 保守整合
1. **保持现有结构**:
   - 保留所有现有目录
   - 只修复命名和结构问题

2. **建立映射关系**:
   - 创建目录映射文档
   - 明确各目录职责范围

3. **逐步迁移**:
   - 新测试按新结构组织
   - 旧测试逐步迁移

### 3. 命名规范建议

#### 文件命名规范
```
格式: {component}_{test_type}_test.cpp
示例:
├── sql_parser_unit_test.cpp
├── sql_executor_integration_test.cpp
├── network_performance_test.cpp
└── security_memory_test.cpp
```

#### 目录命名规范
```
使用 snake_case:
├── sql_parser/     # 而不是 sql-parser/
├── storage_engine/ # 而不是 storage-engine/
└── unit_tests/     # 而不是 unit-tests/
```

### 4. BUILD文件规范

#### 统一格式要求
- 所有BUILD文件使用 `BUILD.bazel` 扩展名
- 统一load语句格式
- 标准化依赖声明
- 统一测试目标命名

#### 配置模板
```python
# BUILD.bazel 模板
load("@rules_cc//cc:defs.bzl", "cc_test")

package(default_visibility = ["//visibility:public"])

cc_test(
    name = "component_test_type_test",
    srcs = ["component_test_type_test.cpp"],
    deps = [
        "//src/component",
        "@gtest//:gtest_main",
    ],
    copts = ["-std=c++20"],
)
```
