## 审计方法论

### 静态分析工具
- **AddressSanitizer (ASan)**: 检测缓冲区溢出、使用已释放内存
- **ThreadSanitizer (TSan)**: 检测数据竞争和死锁
- **UndefinedBehaviorSanitizer (UBSan)**: 检测未定义行为
- **Valgrind**: 内存泄漏检测和内存使用分析

### 动态检测方法
- **压力测试**: 高并发场景下的内存稳定性
- **长期运行测试**: 24小时连续运行的内存泄漏检测
- **异常注入**: 模拟各种异常情况的内存安全验证
- **边界条件测试**: 测试边界条件下的内存行为

### 代码审查标准
- **C++ Core Guidelines**: 遵循现代C++最佳实践
- **SEI CERT C++**: 安全编码标准
- **Google C++ Style Guide**: 代码风格和质量标准
- **自定义规则**: 项目特定的内存安全规则

#### 2.4 网络模块RAII重构
**文件**: `src/network/` 目录下多个文件
**问题数量**: 156个
**重构内容**:
```cpp
// SSL上下文管理
class SSLContext {
    SSL_CTX* ctx_;
public:
    SSLContext() : ctx_(SSL_CTX_new(TLS_method())) {
        if (!ctx_) throw std::runtime_error("SSL_CTX creation failed");
    }
    ~SSLContext() { if (ctx_) SSL_CTX_free(ctx_); }
    
    // 禁止拷贝，允许移动
    SSLContext(const SSLContext&) = delete;
    SSLContext& operator=(const SSLContext&) = delete;
    SSLContext(SSLContext&& other) noexcept : ctx_(other.ctx_) {
        other.ctx_ = nullptr;
    }
};
```

**资源管理改进**:
- SSL资源自动管理
- 异常安全保证
- 代码简洁性提升50%

### 3. 内存安全模式建立

#### 3.1 智能指针使用规范
```cpp
// 独占所有权使用std::unique_ptr
std::unique_ptr<Database> db = std::make_unique<Database>();

// 共享所有权使用std::shared_ptr
std::shared_ptr<Table> table = std::make_shared<Table>();

// 弱引用使用std::weak_ptr避免循环引用
std::weak_ptr<Column> weak_col = column;
```

#### 3.2 RAII设计模式
```cpp
// 文件句柄管理
class FileDescriptor {
    int fd_;
public:
    FileDescriptor(int fd) : fd_(fd) {}
    ~FileDescriptor() { if (fd_ >= 0) close(fd_); }
    
    // 移动语义支持
    FileDescriptor(FileDescriptor&& other) noexcept : fd_(other.fd_) {
        other.fd_ = -1;
    }
};
```

#### 3.3 异常安全保证
```cpp
// 强异常安全保证
class Transaction {
    std::vector<Operation> operations_;
    State backup_state_;
    
public:
    void commit() {
        // 先备份当前状态
        State current_state = getCurrentState();
        
        try {
            // 执行操作
            for (auto& op : operations_) {
                op.execute();
            }
            
            // 操作成功，更新状态
            updateState(current_state);
        } catch (...) {
            // 操作失败，回滚到备份状态
            restoreState(backup_state_);
            throw; // 重新抛出异常
        }
    }
};
```

## 工具链与自动化

### 静态分析集成
```bash
# Bazel构建配置中添加Sanitizer支持
# .bazelrc 配置
build:asan --strip=never
build:asan --copt=-fsanitize=address
build:asan --copt=-DADDRESS_SANITIZER
build:asan --copt=-O1
build:asan --copt=-g
build:asan --copt=-fno-omit-frame-pointer
build:asan --linkopt=-fsanitize=address
```

### CI/CD集成
```yaml
# GitHub Actions 配置示例
- name: Run AddressSanitizer
  run: |
    bazel test --config=asan //src:all_tests
    
- name: Run Valgrind
  run: |
    valgrind --leak-check=full --error-exitcode=1 ./bazel-bin/src/sqlcc_test
    
- name: Memory Safety Report
  run: |
    ./scripts/generate_memory_report.sh
```

### 自动化检测脚本
```bash
#!/bin/bash
# memory_audit.sh - 内存安全审计脚本

echo "开始内存安全审计..."

# 1. AddressSanitizer 检测
echo "运行 AddressSanitizer..."
bazel test --config=asan //src:all_tests --test_output=errors > asan_report.txt

# 2. ThreadSanitizer 检测  
echo "运行 ThreadSanitizer..."
bazel test --config=tsan //src:concurrent_tests > tsan_report.txt

# 3. Valgrind 内存泄漏检测
echo "运行 Valgrind..."
valgrind --leak-check=full --show-leak-kinds=all \
         --track-origins=yes --verbose \
         ./bazel-bin/src/sqlcc_test > valgrind_report.txt 2>&1

# 4. 生成综合报告
echo "生成审计报告..."
./scripts/compile_memory_report.py asan_report.txt tsan_report.txt valgrind_report.txt

echo "内存安全审计完成！"
```
