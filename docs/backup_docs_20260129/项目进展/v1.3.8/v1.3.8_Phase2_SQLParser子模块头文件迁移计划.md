## 🔧 迁移重构规范

### 1. 目录结构规范
```
src/sql_parser/[submodule]/
├── include/           # 头文件目录
│   ├── [submodule]_*.h
│   └── internal/      # 内部头文件（可选）
├── [submodule]_*.cpp  # 源文件
└── BUILD.bazel       # 子模块BUILD文件（可选）
```

### 2. 头文件包含规范
- **内部包含**: 使用相对路径 `"[header].h"`
- **跨模块包含**: 使用完整路径 `"src/sql_parser/[submodule]/include/[header].h"`
- **外部包含**: 使用完整路径 `"src/[module]/[header].h"`

### 3. BUILD.bazel规范
- 每个子模块维护独立的BUILD.bazel
- 清晰定义依赖关系
- 正确配置include路径
- 提供向后兼容的alias

### 4. 测试验证规范
- **编译测试**: 确保子模块编译通过
- **单元测试**: 运行相关单元测试
- **集成测试**: 验证跨模块依赖
- **回归测试**: 确保现有功能不受影响
