## AI开发原则

### 核心准则
遵循AI驱动的软件开发最佳实践，确保代码质量和开发效率：

#### 1. 编译器强制要求
- **必须使用**：clang-20 编译器
- **禁止使用**：gcc 或其他编译器
- **原因**：clang-20 提供更好的C++20支持和更严格的代码检查

#### 2. 构建工具版本控制
- **Bazel版本**：8.5（强制升级）
- **CMake版本**：最新稳定版
- **目的**：确保构建一致性和依赖管理

#### 3. 代码质量标准
- **静态分析**：强制通过clang-tidy检查
- **代码覆盖率**：≥80%
- **单元测试**：每个功能模块必须有对应的测试

#### 4. 开发流程规范
- **代码审查**：所有代码变更必须经过审查
- **自动化测试**：提交前必须通过所有自动化测试
- **文档同步**：代码变更必须同步更新相关文档

#### 5. 架构设计原则
- **分层架构**：严格遵循8层架构设计
- **模块化**：高内聚、低耦合的设计理念
- **可扩展性**：为未来功能预留扩展接口

#### 6. 性能优化准则
- **基准测试**：建立性能基准并持续监控
- **内存管理**：避免内存泄漏，优化内存使用
- **并发处理**：合理使用多线程和异步处理
