## 问题与解决方案

### 遇到的主要问题

1. **BUILD文件语法错误**
   - 问题：`tests/integration/BUILD.bazel`中`linkopts`和`copts`属性位置错误
   - 解决方案：将这些属性移入`cc_test`规则内部

2. **集成测试编译失败**
   - 问题：集成测试依赖的源文件可能存在编译错误
   - 解决方案：跳过集成测试，专注于单元测试覆盖率收集

### 技术挑战

1. **Bazel覆盖率配置复杂性**
   - 需要正确配置编译选项和链接选项
   - 环境变量设置必须与编译选项匹配

2. **覆盖率数据收集限制**
   - 当前仅收集到基础工具类的覆盖率数据
   - 需要扩展到更多核心组件
