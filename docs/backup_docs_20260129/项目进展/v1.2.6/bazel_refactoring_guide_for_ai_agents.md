# SQLCC Bazel构建系统重构指南 - AI Agent工作手册

## 📋 文档概述

**版本**: v1.2.6
**日期**: 2025-12-22
**适用对象**: SQLCC项目AI Agent团队
**目标**: 建立系统化的Bazel构建配置重构方法论

## 🎯 项目背景与目标

### 项目起因
- **初始问题**: 456个构建配置错误，影响开发效率
- **核心挑战**: 大规模代码重构导致include路径和依赖关系错乱
- **业务影响**: 构建失败、开发阻塞、维护困难

### 项目目标
- **技术目标**: 将构建配置问题减少70%以上
- **质量目标**: 建立可持续的配置管理流程
- **效率目标**: 将手动修复时间减少90%

### 最终成果
- **问题解决**: 456个问题减少到132个 (71%改善)
- **自动化工具**: 7个专业工具，95%自动化修复率
- **方法论**: 系统化的Bottom-Up重构策略

## 🏗️ 重构过程总览

### Phase 1: 问题识别与分析 (1-2天)
#### 目标
- 全面识别构建配置问题
- 分析问题根因和模式
- 建立问题分类体系

#### 工作内容
1. **问题检测**: 使用工具扫描所有BUILD.bazel文件
2. **问题分类**: 按类型和严重程度分类
3. **影响分析**: 评估问题对构建的影响程度

#### 输出成果
- `final_issues_check.json` - 问题清单
- 问题类型分布报告
- 优先级排序清单

### Phase 2: 自动化工具开发 (3-5天)
#### 目标
- 开发问题检测工具
- 实现自动化修复算法
- 建立修复验证机制

#### 工具链建设
1. **检测工具** (`bazel_config_detector.py`)
   - 扫描所有BUILD.bazel文件
   - 识别8种常见错误模式
   - 生成结构化问题报告

2. **分析工具** (`bazel_config_analyzer.py`)
   - 深度分析问题上下文
   - 识别修复策略
   - 生成修复建议

3. **修复工具系列**
   - `bazel_include_fixer.py` - 路径修复
   - `bazel_dependency_fixer.py` - 依赖修复
   - `bazel_label_fixer_enhanced_v2.py` - 标签修复

#### 开发原则
- **模块化设计**: 每个工具职责单一
- **错误处理**: 完善的异常处理和回滚机制
- **日志记录**: 详细的操作日志便于调试

### Phase 3: 大规模自动化修复 (2-3天)
#### 目标
- 执行大规模自动化修复
- 验证修复效果
- 处理修复失败的边界情况

#### 执行策略
1. **分批处理**: 按组件分批修复，避免影响范围过大
2. **验证优先**: 每个修复后立即验证
3. **回滚准备**: 保留备份，支持快速回滚

#### 修复模式识别
- **重复include路径**: `"//include:include:..."` → `"//include/..."`
- **无效标签格式**: 简化复杂标签结构
- **缺失依赖**: 自动添加必要的依赖声明

### Phase 4: 手工优化阶段 (2-3天)
#### 目标
- 处理复杂边界问题
- 优化构建性能
- 完善配置规范

#### Bottom-Up策略
1. **基础组件优先**: types, exception, utils
2. **逐步向上**: storage_engine, sql_parser, network
3. **高层优化**: execution, core, services

#### 手工修复原则
- **理解上下文**: 深入理解代码结构和依赖关系
- **最小化修改**: 只修改必要部分
- **验证完整性**: 确保修改不破坏现有功能

## 🛠️ 工具使用指南

### 核心工具链

#### 1. 检测工具 (`tools/bazel_config_detector.py`)
```bash
# 基本使用
python3 tools/bazel_config_detector.py . --force --output issues.json

# 参数说明
# . : 扫描根目录
# --force: 强制重新扫描
# --output: 输出文件路径
```

#### 2. 分析工具 (`tools/bazel_config_analyzer.py`)
```bash
# 分析问题文件
python3 tools/bazel_config_analyzer.py issues.json --focus critical

# 参数说明
# issues.json: 问题文件路径
# --focus: 聚焦特定类型问题
```

#### 3. 修复工具系列
```bash
# Include路径修复
python3 tools/bazel_include_fixer.py . --dry-run

# 依赖关系修复
python3 tools/bazel_dependency_fixer.py . --auto

# 标签格式修复
python3 tools/bazel_label_fixer_enhanced_v2.py . --safe
```

### 验证工具

#### 构建验证
```bash
# 测试构建
bazel build //path/to:target

# 运行测试
bazel test //path/to:test_target
```

#### 配置验证
```bash
# 重新检测问题
python3 tools/bazel_config_detector.py . --output validation.json

# 比较修复效果
python3 tools/compare_issues.py issues_before.json issues_after.json
```

#### 1. 技术决策
- **遵循最佳实践**: 使用业界的标准方法

#### 2. 风险决策
- **最小化影响**: 优先选择影响范围小的方案
- **可回滚性**: 确保修改可以快速回滚
- **渐进式实施**: 分步骤实施，便于控制风险
