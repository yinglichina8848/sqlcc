- 使用大量mock和简化类实现

## 测试设计原则
1. **真实性**：直接测试核心源码类，不使用mock简化类
2. **全面性**：覆盖所有公共接口和边界条件
3. **错误发现**：设计能够发现真实代码错误的测试用例
4. **独立性**：测试之间不互相依赖
5. **可维护性**：测试代码清晰，易于理解和修改

## 预期成果
- 所有网络模块测试都基于真实的核心类

- 测试能有效发现代码中的bug和逻辑错误
