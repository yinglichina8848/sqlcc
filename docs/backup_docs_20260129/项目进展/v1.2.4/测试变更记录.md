## v1.2.3 原始变更记录（继承内容）

### 概述
本次测试改进主要针对编译和运行错误进行了修复，解决了头文件组织、构建配置和代码API兼容性等问题。

### 主要变更

#### 1. 头文件包含路径修复 (2025-12-19)
- **问题**: 源码文件使用错误的头文件包含路径
- **解决**: 修复 `src/sql_parser/set_operation.cpp`, `window_function.cpp`, `recursive_query.cpp` 中的包含路径
- **影响**: 确保头文件能正确解析和包含

#### 2. BUILD.bazel 配置修复 (2025-12-19)
- **问题**: 多个库缺少includes配置，导致头文件查找失败
- **解决**: 为 `set_operation`, `window_function`, `recursive_query` 库添加 `includes = ["../../include"]`
- **影响**: 修复了编译错误，使新功能模块能正常构建

#### 3. ExecutionResult API 兼容性 (2025-12-19)
- **问题**: `set_operation_executor.cpp` 使用了不存在的ExecutionResult成员
- **解决**: 将 `error_message` 改为 `message`，将 `rows_affected` 改为 `rows.size()`
- **影响**: 修复了编译错误，使执行器代码与实际API兼容
