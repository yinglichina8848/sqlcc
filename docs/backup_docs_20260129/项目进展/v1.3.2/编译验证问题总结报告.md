
### 方案2: 简化Bazel编译
```bash
# 使用最小化编译选项
bazel build \
  --jobs=1 \
  --local_resources=memory=1024 \
  --compilation_mode=opt \
  //tests/level5_execution/execution_context:execution_context_test

# 分阶段编译
bazel build //src/core:core
bazel build //tests/level5_execution/execution_context:execution_context_test
```
