#### **Utils Test - Numeric Validation 修复**
**问题**: 使用`::isdigit`可能在不同环境下表现不一致

```cpp
// 修复前 - 可能不稳定的isdigit
auto is_numeric = [](const std::string& str) {
    return !str.empty() && std::all_of(str.begin(), str.end(), ::isdigit);
};

// 修复后 - 确定性的字符范围检查
auto is_numeric = [](const std::string& str) {
    if (str.empty()) return false;
    for (char c : str) {
        if (c < '0' || c > '9') return false;
    }
    return true;
};
```

**结果**: ✅ Numeric validation测试稳定通过
