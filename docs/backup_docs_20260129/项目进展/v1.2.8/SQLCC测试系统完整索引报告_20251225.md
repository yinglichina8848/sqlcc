## 🚀 测试执行指南

### 快速开始
```bash
# 1. 编译基础测试
bazel build //tests/unit/basic:logger_basic_test

# 2. 运行基础测试
bazel run //tests/unit/basic:logger_basic_test

# 3. 编译核心测试
bazel build //tests/unit/core/...

# 4. 运行集成测试
bazel test //tests/integration/...
```

### 分阶段执行建议
```bash
# Phase 1: 单元测试
bazel test //tests/unit/... --test_timeout=60

# Phase 2: 集成测试  
bazel test //tests/integration/... --test_timeout=300

# Phase 3: 性能测试
bazel test //tests/performance/... --test_timeout=600
```

### 故障排除
1. **编译失败**: 检查BUILD文件语法和依赖关系
2. **运行失败**: 检查环境配置和外部服务
3. **超时问题**: 调整测试超时时间或优化环境
4. **资源不足**: 增加系统资源或减少并发测试
