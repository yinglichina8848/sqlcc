### 具体问题详情

#### 1. BUILD配置问题
**问题**: `//src/procedure:procedure`目标不存在
**影响**: 导致data_types_test等测试无法编译
**根本原因**: BUILD文件依赖声明错误
**修复方案**:
```bazel
# 修改前 (错误)
deps = [
    "//src/procedure:procedure",  # 不存在的目标
]

# 修改后 (正确)
deps = [
    "//src/procedure:procedure_parser",
    "//src/procedure:procedure_vm",
    "//src/procedure:procedure_trigger_executor",
]
```

#### 2. 环境资源限制
**问题**: 大型测试编译超时
**影响**: 无法完成完整测试验证
**根本原因**: 环境资源不足
**修复方案**:
- 增加系统内存
- 优化编译并行度
- 分批执行测试

#### 3. 依赖关系复杂
**问题**: 测试间依赖关系复杂
**影响**: 编译顺序敏感
**根本原因**: 项目模块耦合度高
**修复方案**:
- 建立依赖关系图
- 优化编译顺序
- 减少不必要依赖
