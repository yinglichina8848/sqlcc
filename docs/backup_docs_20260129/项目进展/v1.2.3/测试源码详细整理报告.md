- **execution_engine库**: 多个集成测试引用了不存在的 `//src/execution:execution` 库
- **可见性设置**: 需要修复库的可见性声明

#### 4. 运行时逻辑问题
- **b_plus_tree_test**: 运行时出现递归深度超限错误
- **buffer_pool_test**: 运行时出现页面管理错误
