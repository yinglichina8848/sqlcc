# SQLCC v1.2.3 内存安全修复代码示例指南

## 1. 智能指针替换模式

### 1.1 独占所有权替换 (std::unique_ptr)

#### 场景: B+树节点管理
**修复前 (高风险):**
```cpp
// b_plus_tree.cpp - 高风险裸指针
BPlusTreeNode* CreateNewNode() {
    BPlusTreeNode* node = new BPlusTreeNode(); // 手动内存管理
    node->Initialize();
    return node; // 调用者需要手动delete
}

void ProcessNode() {
    BPlusTreeNode* node = CreateNewNode();
    // ... 使用node
    delete node; // 容易忘记导致内存泄漏
}
```

**修复后 (安全):**
```cpp
// b_plus_tree.cpp - 智能指针管理
std::unique_ptr<BPlusTreeNode> CreateNewNode() {
    auto node = std::make_unique<BPlusTreeNode>();
    node->Initialize();
    return node; // 自动管理生命周期
}

void ProcessNode() {
    auto node = CreateNewNode();
    // ... 使用node
    // 自动释放，无需手动delete
}
```

### 1.2 共享所有权替换 (std::shared_ptr)

#### 场景: 页面缓冲池管理
**修复前 (中风险):**
```cpp
// buffer_pool.cpp - 手动引用计数
Page* FetchPage(int32_t page_id) {
    Page* page = FindInCache(page_id);
    if (!page) {
        page = LoadFromDisk(page_id);
        AddToCache(page_id, page);
    }
    return page; // 调用者需要管理生命周期
}

void UsePage() {
    Page* page = buffer_pool->FetchPage(123);
    // 多个组件可能同时使用该页面
    // 需要复杂的引用计数管理
}
```

**修复后 (安全):**
```cpp
// buffer_pool.cpp - 自动引用计数
std::shared_ptr<Page> FetchPage(int32_t page_id) {
    std::shared_ptr<Page> page = FindInCache(page_id);
    if (!page) {
        page = std::make_shared<Page>(LoadFromDisk(page_id));
        AddToCache(page_id, page);
    }
    return page; // 自动管理生命周期
}

void UsePage() {
    auto page = buffer_pool->FetchPage(123);
    // 多个组件可以安全共享
    // 自动引用计数，最后一个使用者释放
}
```

## 2. RAII模式应用示例

### 2.1 文件描述符RAII封装

**修复前 (高风险):**
```cpp
// network.cpp - 手动资源管理
void HandleConnection(int client_fd) {
    // 处理连接
    process_request(client_fd);
    
    // 容易忘记关闭文件描述符
    // close(client_fd);
}
```

**修复后 (安全):**
```cpp
// utils/file_descriptor_raii.h
class FileDescriptorRAII {
public:
    explicit FileDescriptorRAII(int fd = -1) : fd_(fd) {}
    
    ~FileDescriptorRAII() {
        if (fd_ >= 0) {
            ::close(fd_);
            fd_ = -1;
        }
    }
    
    // 禁止拷贝，允许移动
    FileDescriptorRAII(const FileDescriptorRAII&) = delete;
    FileDescriptorRAII& operator=(const FileDescriptorRAII&) = delete;
    
    FileDescriptorRAII(FileDescriptorRAII&& other) noexcept 
        : fd_(other.fd_) {
        other.fd_ = -1;
    }
    
    FileDescriptorRAII& operator=(FileDescriptorRAII&& other) noexcept {
        if (this != &other) {
            reset();
            fd_ = other.fd_;
            other.fd_ = -1;
        }
        return *this;
    }
    
    int get() const { return fd_; }
    
    void reset(int new_fd = -1) {
        if (fd_ >= 0) {
            ::close(fd_);
        }
        fd_ = new_fd;
    }
    
private:
    int fd_;
};

// network.cpp - 自动资源管理
void HandleConnection(int client_fd) {
    FileDescriptorRAII fd_raii(client_fd);
    
    // 处理连接
    process_request(fd_raii.get());
    
    // 自动关闭文件描述符
}
```

### 2.2 SSL连接RAII封装

**修复前 (高风险):**
```cpp
// ssl_wrapper.cpp - 手动SSL管理
class SSLWrapper {
public:
    SSLWrapper(SSL_CTX* ctx) {
        ssl_ = SSL_new(ctx); // 可能失败
    }
    
    ~SSLWrapper() {
        if (ssl_) {
            SSL_free(ssl_); // 可能忘记调用
        }
    }
    
private:
    SSL* ssl_ = nullptr; // 未初始化指针风险
};
```

**修复后 (安全):**
```cpp
// utils/secure_ssl_wrapper.h
class SecureSSLWrapper {
public:
    static std::unique_ptr<SecureSSLWrapper> Create(SSL_CTX* ctx) {
        if (!ctx) {
            throw std::invalid_argument("SSL_CTX cannot be null");
        }
        
        SSL* ssl = SSL_new(ctx);
        if (!ssl) {
            throw std::runtime_error("SSL creation failed");
        }
        
        return std::unique_ptr<SecureSSLWrapper>(new SecureSSLWrapper(ssl));
    }
    
    ~SecureSSLWrapper() {
        if (ssl_) {
            SSL_free(ssl_);
            ssl_ = nullptr;
        }
    }
    
    // 禁止拷贝，允许移动
    SecureSSLWrapper(const SecureSSLWrapper&) = delete;
    SecureSSLWrapper& operator=(const SecureSSLWrapper&) = delete;
    
    SecureSSLWrapper(SecureSSLWrapper&& other) noexcept 
        : ssl_(other.ssl_) {
        other.ssl_ = nullptr;
    }
    
    SecureSSLWrapper& operator=(SecureSSLWrapper&& other) noexcept {
        if (this != &other) {
            reset();
            ssl_ = other.ssl_;
            other.ssl_ = nullptr;
        }
        return *this;
    }
    
    SSL* get() const { return ssl_; }
    
    void reset(SSL* new_ssl = nullptr) {
        if (ssl_) {
            SSL_free(ssl_);
        }
        ssl_ = new_ssl;
    }
    
private:
    explicit SecureSSLWrapper(SSL* ssl) : ssl_(ssl) {}
    
    SSL* ssl_;
};
```

## 3. 边界检查与安全访问

### 3.1 安全数组访问

**修复前 (低风险):**
```cpp
// 不安全的数组访问
char buffer[1024];
void unsafe_copy(const char* src, size_t len) {
    // 可能缓冲区溢出
    memcpy(buffer, src, len);
}
```

**修复后 (安全):**
```cpp
// utils/safe_container.h
template<typename T>
class SafeArray {
public:
    explicit SafeArray(size_t size) 
        : data_(std::make_unique<T[]>(size)), size_(size) {}
    
    T& operator[](size_t index) {
        if (index >= size_) {
            throw std::out_of_range("SafeArray index out of bounds: " + 
                                 std::to_string(index) + " >= " + 
                                 std::to_string(size_));
        }
        return data_[index];
    }
    
    const T& operator[](size_t index) const {
        if (index >= size_) {
            throw std::out_of_range("SafeArray index out of bounds: " + 
                                 std::to_string(index) + " >= " + 
                                 std::to_string(size_));
        }
        return data_[index];
    }
    
    size_t size() const { return size_; }
    
    // 安全拷贝操作
    void safe_copy(const T* src, size_t count) {
        if (count > size_) {
            throw std::out_of_range("Copy size exceeds array capacity");
        }
        std::copy_n(src, count, data_.get());
    }
    
private:
    std::unique_ptr<T[]> data_;
    size_t size_;
};

// 安全的使用方式
SafeArray<char> buffer(1024);
void safe_copy(const char* src, size_t len) {
    buffer.safe_copy(src, len); // 自动边界检查
}
```

### 3.2 字符串安全操作

**修复前 (低风险):**
```cpp
// 不安全的字符串操作
void unsafe_string_operation(const char* str) {
    char buffer[256];
    strcpy(buffer, str); // 可能缓冲区溢出
}
```

**修复后 (安全):**
```cpp
// utils/string_safety.h
class SafeString {
public:
    SafeString(const char* str, size_t max_len = 1024) {
        if (!str) {
            throw std::invalid_argument("String cannot be null");
        }
        
        size_t len = std::strlen(str);
        if (len > max_len) {
            throw std::length_error("String length exceeds maximum allowed");
        }
        
        data_ = std::make_unique<char[]>(len + 1);
        std::strcpy(data_.get(), str);
    }
    
    // 安全拷贝到缓冲区
    void copy_to(char* dest, size_t dest_size) const {
        if (!dest) {
            throw std::invalid_argument("Destination buffer cannot be null");
        }
        
        size_t src_len = std::strlen(data_.get());
        if (src_len >= dest_size) {
            throw std::out_of_range("Destination buffer too small");
        }
        
        std::strncpy(dest, data_.get(), dest_size - 1);
        dest[dest_size - 1] = '\0';
    }
    
    const char* c_str() const { return data_.get(); }
    
private:
    std::unique_ptr<char[]> data_;
};

// 安全的使用方式
void safe_string_operation(const char* str) {
    SafeString safe_str(str);
    char buffer[256];
    safe_str.copy_to(buffer, sizeof(buffer)); // 自动边界检查
}
```

## 4. 自定义删除器模式

### 4.1 缓冲池页面自定义删除器

```cpp
// storage/page_lifetime_manager.h
class PageLifetimeManager {
public:
    // 自定义删除器用于缓冲池页面
    struct PageDeleter {
        explicit PageDeleter(std::shared_ptr<StorageEngine> engine) 
            : storage_engine_(std::move(engine)) {}
        
        void operator()(Page* page) const {
            if (page && storage_engine_) {
                storage_engine_->UnpinPage(page->GetPageId(), false);
            }
        }
        
    private:
        std::shared_ptr<StorageEngine> storage_engine_;
    };
    
    using SafePagePtr = std::unique_ptr<Page, PageDeleter>;
    
    SafePagePtr CreateSafePage(int32_t page_id, std::shared_ptr<StorageEngine> engine) {
        Page* page = engine->FetchPage(page_id);
        return SafePagePtr(page, PageDeleter(std::move(engine)));
    }
};

// 使用示例
void process_page_safely(int32_t page_id) {
    PageLifetimeManager manager;
    auto safe_page = manager.CreateSafePage(page_id, storage_engine_);
    
    // 使用页面
    safe_page->ReadData(...);
    
    // 自动调用UnpinPage，无需手动管理
}
```

### 4.2 数据库连接自定义删除器

```cpp
// network/connection_manager.h
class ConnectionManager {
public:
    struct ConnectionDeleter {
        void operator()(Connection* conn) const {
            if (conn) {
                try {
                    conn->Close();
                    delete conn;
                } catch (const std::exception& e) {
                    SQLCC_LOG_ERROR("Failed to close connection: " + std::string(e.what()));
                }
            }
        }
    };
    
    using SafeConnectionPtr = std::unique_ptr<Connection, ConnectionDeleter>;
    
    SafeConnectionPtr CreateConnection(const std::string& host, int port) {
        auto conn = std::make_unique<Connection>(host, port);
        conn->Connect();
        return SafeConnectionPtr(conn.release(), ConnectionDeleter{});
    }
};
```

## 5. 异常安全模式

### 5.1 资源获取即初始化 (RAII)

```cpp
// utils/scope_guard.h
class ScopeGuard {
public:
    template<typename Fn>
    explicit ScopeGuard(Fn&& cleanup) 
        : cleanup_(std::forward<Fn>(cleanup)) {}
    
    ~ScopeGuard() {
        if (cleanup_) {
            try {
                cleanup_();
            } catch (...) {
                // 析构函数中不抛出异常
            }
        }
    }
    
    // 禁止拷贝，允许移动
    ScopeGuard(const ScopeGuard&) = delete;
    ScopeGuard& operator=(const ScopeGuard&) = delete;
    
    ScopeGuard(ScopeGuard&& other) noexcept 
        : cleanup_(std::move(other.cleanup_)) {
        other.cleanup_ = nullptr;
    }
    
    ScopeGuard& operator=(ScopeGuard&& other) noexcept {
        if (this != &other) {
            cleanup_ = std::move(other.cleanup_);
            other.cleanup_ = nullptr;
        }
        return *this;
    }
    
    void dismiss() { cleanup_ = nullptr; }
    
private:
    std::function<void()> cleanup_;
};

// 使用示例
void database_operation() {
    auto conn = connection_pool->GetConnection();
    
    // 确保连接总是被释放
    ScopeGuard guard([&conn]() {
        if (conn) {
            connection_pool->ReturnConnection(std::move(conn));
        }
    });
    
    // 执行数据库操作
    conn->Execute("UPDATE table SET value = 1");
    
    // 如果操作成功，取消guard
    guard.dismiss();
    connection_pool->ReturnConnection(std::move(conn));
}
```

## 7. 常见问题与解决方案

### 7.1 循环引用问题

**问题:** shared_ptr导致的循环引用
```cpp
class Node {
public:
    std::shared_ptr<Node> next; // 可能导致循环引用
};

// 循环引用示例
auto node1 = std::make_shared<Node>();
auto node2 = std::make_shared<Node>();
node1->next = node2;
node2->next = node1; // 循环引用，内存泄漏
```

**解决方案:** 使用weak_ptr打破循环引用
```cpp
class SafeNode {
public:
    std::weak_ptr<SafeNode> next; // 使用weak_ptr避免循环引用
    
    std::shared_ptr<SafeNode> get_next() const {
        return next.lock(); // 尝试获取shared_ptr
    }
};
```

### 7.2 性能优化建议

1. **优先使用unique_ptr**: 当所有权独占时，unique_ptr比shared_ptr更高效
2. **使用make_shared/make_unique**: 减少内存分配次数
3. **避免不必要的拷贝**: 使用移动语义传递智能指针
4. **批量操作优化**: 对容器使用reserve避免多次重分配

## 8. 代码审查检查清单

- [ ] 是否使用了裸指针？应该替换为智能指针
