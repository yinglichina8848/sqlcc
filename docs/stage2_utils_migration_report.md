### 1. Logger头文件现代化

#### 优化前后的对比
```cpp
// 优化前 (传统方式)
#pragma once
#include <iostream>
#include <fstream>
#include <string>
// ... 其他includes

// 优化后 (C++20 + Clang 18)
#pragma once
#include <string>          // std::string
#include <memory>          // std::unique_ptr
#include <fstream>         // std::ofstream - needed for unique_ptr member
#include <iosfwd>          // std::ostream forward declaration
```
