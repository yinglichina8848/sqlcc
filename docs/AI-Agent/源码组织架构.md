# SQLCC 源码组织架构详解

## 🏗️ 系统架构总览

SQLCC采用分层架构设计，从客户端到存储引擎形成完整的数据库处理链：

```
┌─────────────────┐
│   ISQL Client   │ ← 命令行交互界面
└─────────────────┘
         │
    网络协议层     ← TCP/自定义协议
         │
┌─────────────────┐
│   SQL解析器     │ ← 词法/语法分析
└─────────────────┘
         │
┌─────────────────┐
│   执行引擎      │ ← 查询优化/执行计划
└─────────────────┘
         │
┌─────────────────┐
│   存储引擎      │ ← 数据持久化/索引
└─────────────────┘
         │
    操作系统I/O
```

## 🔧 核心设计模式应用

### 1. 策略模式 (Execution Strategies)
```cpp
// 不同SQL语句类型使用不同执行策略
std::unique_ptr<ExecutionStrategy> CreateStrategy(Statement::Type type) {
    switch (type) {
        case Statement::Type::SELECT:
            return std::make_unique<DMLExecutionStrategy>();
        case Statement::Type::CREATE_TABLE:
            return std::make_unique<DDLExecutionStrategy>();
        case Statement::Type::GRANT:
            return std::make_unique<DCLExecutionStrategy>();
        default:
            return nullptr;
    }
}
```

### 4. RAII模式 (Resource Management)
```cpp
// 文件描述符RAII封装
class FileDescriptor {
public:
    explicit FileDescriptor(int fd) : fd_(fd) {}
    ~FileDescriptor() { if (fd_ >= 0) close(fd_); }

    // 禁止拷贝
    FileDescriptor(const FileDescriptor&) = delete;
    FileDescriptor& operator=(const FileDescriptor&) = delete;

    // 允许移动
    FileDescriptor(FileDescriptor&& other) noexcept : fd_(other.fd_) {
        other.fd_ = -1;
    }

private:
    int fd_;
};
```

#### 2. 服务器接收处理
```cpp
// 服务器网络层
void ServerNetwork::HandleClientMessage(int client_fd, const Message& msg) {
    switch (msg.type) {
        case MessageType::QUERY: {
            // 解析SQL
            auto stmt = sql_parser_.Parse(msg.body);

            // 执行查询
            auto result = sql_executor_.Execute(std::move(stmt));

            // 发送结果
            SendResponse(client_fd, result);
            break;
        }
    }
}
```

#### 3. SQL解析过程
```cpp
// SQL解析器
std::unique_ptr<Statement> SqlParser::Parse(const std::string& sql) {
    // 词法分析
    auto tokens = lexer_.Tokenize(sql);

    // 语法分析
    return parser_.Parse(std::move(tokens));
}
```

```cpp
// 执行引擎
```

## 📊 性能优化策略

### 1. 缓冲池优化
- **多级缓存**: L1/L2缓存层次结构
- **预取策略**: 基于访问模式的智能预取
- **替换算法**: LRU/LFU/ARC等多种策略

### 2. 索引优化
- **复合索引**: 多列联合索引
- **覆盖索引**: 索引包含查询所需所有列
- **索引选择**: 基于代价的索引选择算法

### 3. 查询优化
- **计划缓存**: 执行计划重用
- **并行执行**: 多核CPU并行处理
- **结果缓存**: 查询结果缓存机制

### 4. 内存管理
- **智能指针**: RAII资源管理
- **对象池**: 减少内存分配开销
- **垃圾回收**: 智能的内存回收策略

## 🎯 AI开发关键要点

### 理解架构的核心原则
1. **分层解耦**: 各层职责清晰，接口抽象
2. **依赖倒置**: 上层不依赖下层具体实现
3. **开闭原则**: 对扩展开放，对修改封闭
4. **单一职责**: 每个类只有一个改变的理由

### 修改代码的指导原则
1. **接口一致性**: 修改实现时保持接口不变
2. **测试先行**: 先写测试，再修改代码
3. **渐进式重构**: 小步快跑，避免大爆炸重构
4. **文档同步**: 代码变更及时更新相关文档

### 调试技巧
1. **日志分级**: 使用不同级别的日志输出
2. **断言检查**: 在关键路径添加断言
3. **单元测试**: 隔离测试单个组件
4. **性能剖析**: 使用工具分析性能瓶颈
