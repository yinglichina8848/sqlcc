## 🎯 头文件设计原则

### 1. 前向声明 (Forward Declarations)
```cpp
// include/storage/buffer_pool.h
#ifndef SQLCC_BUFFER_POOL_H
#define SQLCC_BUFFER_POOL_H

#include <memory>
#include <string>

// 前向声明，避免包含完整定义
class BufferPage;
class Page;

// 缓冲池接口
class BufferPool {
public:
    virtual ~BufferPool() = default;
    virtual std::shared_ptr<BufferPage> FetchPage(int32_t page_id) = 0;
    virtual std::shared_ptr<BufferPage> NewPage() = 0;
    virtual bool FlushPage(int32_t page_id) = 0;
};

#endif // SQLCC_BUFFER_POOL_H
```

### 2. PIMPL模式 (Pointer to Implementation)
```cpp
// include/network/server_network.h
class ServerNetwork {
public:
    ServerNetwork();
    ~ServerNetwork();

    bool Start(int port);
    void Stop();

private:
    class Impl;  // 前向声明实现类
    std::unique_ptr<Impl> pimpl_;  // 指向实现的指针
};
```

### 3. 接口抽象 (Abstract Interfaces)
```cpp
// include/execution/execution_strategy.h
class ExecutionStrategy {
public:
    virtual ~ExecutionStrategy() = default;

    virtual ExecutionResult Execute(std::unique_ptr<sql_parser::Statement> stmt,
                                   ExecutionContext& context) = 0;

protected:
    ExecutionStrategy() = default;
};
```

## 📋 头文件包含规范

### 1. 自包含性 (Self-Contained)
每个头文件必须是自包含的，能够独立编译：
```cpp
// ❌ 错误示例 - 需要先包含其他头文件
#include "other_header.h"  // 缺少此行会编译失败

class MyClass {
    OtherType member_;  // 使用了未定义的类型
};
```

```cpp
// ✅ 正确示例 - 自包含
#ifndef MY_HEADER_H
#define MY_HEADER_H

#include "other_header.h"  // 明确包含依赖

class MyClass {
    OtherType member_;  // 类型已定义
};

#endif // MY_HEADER_H
```

### 2. 最小化包含 (Minimal Includes)
- 只包含必要的头文件
- 使用前向声明替代完整定义
- 在实现文件中包含具体定义

```cpp
// include/my_class.h
#ifndef MY_CLASS_H
#define MY_CLASS_H

#include <memory>        // 必需的智能指针
#include <string>        // 必需的字符串

class OtherClass;        // 前向声明，避免包含完整定义

class MyClass {
public:
    void SetOther(std::shared_ptr<OtherClass> other);

private:
    std::string name_;
    std::shared_ptr<OtherClass> other_;  // PIMPL模式
};

#endif // MY_CLASS_H
```

### 3. 循环依赖避免
```cpp
// ❌ 循环依赖示例
// A.h
#include "B.h"

// B.h
#include "A.h"

// 解决方案：使用前向声明
// A.h
class B;  // 前向声明

class A {
    std::shared_ptr<B> b_;
};

// B.h
#include "A.h"  // 在B的实现中包含A

class B {
    std::shared_ptr<A> a_;
};
```

## 🎯 AI开发注意事项

### 理解头文件的关键点
1. **接口vs实现**: 头文件定义接口，实现文件提供实现
2. **依赖管理**: 最小化头文件依赖，慎用#include
3. **前向声明**: 优先使用前向声明减少编译时间
4. **PIMPL模式**: 复杂类使用PIMPL隐藏实现细节

### 修改头文件的指导原则
1. **保持兼容性**: 修改接口时保持向后兼容
2. **文档同步**: 更新头文件注释和文档
3. **测试验证**: 修改后运行相关测试验证
4. **依赖检查**: 确保不会引入循环依赖

### 常见问题排查
1. **编译错误**: 检查是否缺少必要的#include
2. **链接错误**: 确认符号定义在对应的.cpp文件中
3. **循环依赖**: 使用前向声明和PIMPL模式解决
4. **类型未定义**: 检查头文件包含顺序
