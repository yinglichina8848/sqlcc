# SQLCC v1.1.5 ChangeLog

## [v1.1.5] - 2025-12-16

### 🎯 概述
v1.1.5版本继续深化内存安全修复工作，重点关注测试系统重构和C++20模块迁移。通过完善测试覆盖率和模块化重构，进一步提升了代码质量和开发效率。

### 🔧 核心改进

#### 测试系统重构
**重构范围**: 单元测试、集成测试、边界测试
**重构目标**: 提升测试覆盖率至50%以上
**重构成果**: 测试框架标准化，覆盖率显著提升

**具体改进**:
- **测试文件重组**: 将40+个测试文件重新组织到tests/unit目录
- **相对路径修复**: 修复40个测试文件中的include路径问题
- **CMake配置优化**: 更新CMakeLists.txt，支持完整的测试框架构建
- **边界条件测试**: 新增15+个边界条件测试用例

#### C++20模块迁移探索
**迁移范围**: 日志模块、用户管理模块
**迁移策略**: 渐进式模块迁移评估
**技术验证**: 探索C++20模块在大型项目中的应用可能性

**具体工作**:
- **模块化编译测试**: 验证clang18对C++20模块的支持
- **传统编译对比**: 对比模块化编译与传统编译的性能差异
- **迁移路径评估**: 制定大型项目的C++20模块迁移策略

#### 存储过程与触发器实现
**新增功能**: 存储过程解析器、触发器执行器
**技术实现**: 完善PL/SQL语法支持
**集成验证**: 与现有SQL执行引擎无缝集成
