#### 常见错误修复
1. **头文件找不到**
   - 问题：模块间头文件引用路径错误
   - 解决：统一include路径格式，使用相对路径

2. **依赖目标不存在**
   问题：BUILD.bazel中引用的目标未定义
   解决：添加缺失的目标定义，修正依赖引用

3. **库定义重复**
   - 问题：同一目标多次定义
   - 解决：合并重复定义，规范化库配置

4. **test_suite配置错误**
   - 问题：test_suite引用不存在的测试
   - 解决：修正test_suite配置，添加缺失测试
