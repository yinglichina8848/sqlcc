# SQLCC v1.1.4 ChangeLog

## [v1.1.4] - 2025-12-15

### 🎯 概述
v1.1.4版本是SQLCC项目的重大里程碑版本，首次实现了全面的内存安全深度修复。通过从下向上的层次化修复策略，对B+树索引系统、网络通信模块和表存储系统进行了系统性的安全加固，显著提升了系统的稳定性和安全性。

### 🔧 核心改进

#### 内存安全深度修复
**修复范围**: B+树索引系统、网络通信模块、表存储系统
**修复策略**: 从下向上层次化修复（基础层→工具层→核心服务层）
**修复成果**: 消除620个内存管理审计发现中的主要风险

**具体修复内容**:
- **B+树索引系统深度修复**: 修复递归插入/删除逻辑、编译错误和段错误
- **网络通信模块深度修复**: 强化连接建立和数据发送的安全检查
- **表存储系统深度修复**: 完善页面分配和记录操作的边界验证

#### SQL解析器功能增强
**新增功能**:
- 实现CREATE TABLE语句完整解析功能
- 实现ALTER TABLE语句解析（ADD/DROP/MODIFY COLUMN, RENAME TO）
- 实现DROP语句解析（TABLE/DATABASE/INDEX + IF EXISTS子句）
- 实现SELECT和INSERT语句基础解析

**技术实现**:
- 重构Parser类架构，统一API接口
- 新增词法分析器关键字支持（INTO, VALUES, TO等）
- 完善错误处理和语法验证机制

#### 测试系统全面评估
**测试覆盖率**: 28% → 40%+
**新增测试用例**: 15+个边界条件测试
**测试框架**: 完善单元测试和集成测试组织
