# SQLCC v1.2.8 BUILD系统重构与标准化

## 版本信息
- **版本号**: v1.2.8
- **发布日期**: 2025-12-24
- **版本类型**: 构建系统重构版

## 🎯 版本目标
本次版本升级的主要目标是：
1. 解决BUILD系统中的标签引用和依赖关系问题
2. 实现构建系统的标准化和规范化
3. 消除重复代码和循环依赖
4. 提升构建稳定性和开发效率

## ✨ 核心改进

### 1. BUILD系统标签引用修复
- **标签格式统一**: 修复78个Bazel标签引用错误
  - 将不规范的标签格式统一为标准格式 `//package/subpackage:target`
  - 修正包路径和文件名混淆的问题
  - 统一sql_parser包目标名称为sqlcc_parser

- **依赖关系优化**: 移除循环依赖和冗余依赖
  - 清理core模块对utils的间接依赖
  - 重构config_manager依赖关系
  - 优化模块间依赖层次

### 2. 重复代码清理
- **Logger库去重**: 解决Logger库重复定义问题
  - 移除logger.cpp，保留功能完整的logger_module_impl.cpp
  - 统一Logger接口和实现
  - 确保符号链接的唯一性

### 3. 构建配置标准化
- **Bazel语法规范**: 统一所有BUILD.bazel文件的语法格式
- **包结构优化**: 优化15个主要BUILD.bazel文件的包定义
- **构建目标分类**: 明确区分cc_library、cc_binary和cc_test目标

### 4. C++20迁移准备
- **编译器兼容性**: 验证C++20标准支持
- **构建环境优化**: 优化编译参数和链接选项
- **依赖库更新**: 更新第三方库到兼容版本
