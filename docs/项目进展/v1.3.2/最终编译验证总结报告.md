## 📚 技术总结

### 经验教训

1. **依赖管理至关重要**: BUILD.bazel中的小错误可能导致严重问题
2. **缓存管理影响重大**: 过时的缓存信息会导致解析错误
3. **编码问题隐蔽性强**: UTF-8编码问题可能导致难以察觉的解析失败

### 最佳实践

1. **依赖引用检查**: 总是验证依赖目标的实际存在性
2. **文件编码规范**: 确保所有配置文件使用纯UTF-8编码
3. **缓存管理**: 遇到奇怪问题时及时清理Bazel缓存

### 工具使用建议

1. **问题诊断**: 使用 `> output.log 2>&1` 重定向输出进行详细分析
2. **依赖验证**: 使用 `bazel query 'deps(//target)'` 验证依赖关系
3. **缓存清理**: 定期执行 `bazel clean --expunge`
