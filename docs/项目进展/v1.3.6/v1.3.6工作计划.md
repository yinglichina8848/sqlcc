## 📋 标准BUILD.bazel模板

### **通用测试模板**
```bazel
cc_test(
    name = "[test_name]_tests",
    srcs = glob(["*.cpp"]),
    deps = [
        "//include/[module]:[module]_headers",
        "//src/[module]:[module]_libs",
        "@com_google_googletest//:gtest_main",
    ],
    copts = [
        "-std=c++20",
        "-fprofile-instr-generate",
        "-fcoverage-mapping",
    ],
    linkopts = ["-fprofile-instr-generate"],
    tags = ["coverage", "level[X]", "[module]"],
)
```

### **依赖配置说明**
- **include路径**: `//include/[module]:[module]_headers`
- **源代码库**: `//src/[module]:[module]_libs`
- **测试框架**: `@com_google_googletest//:gtest_main`
- **编译选项**: C++20 + 覆盖率插桩
- **标签配置**: coverage + level + module
