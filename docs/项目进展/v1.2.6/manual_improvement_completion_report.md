## 📋 技术经验总结

### Bazel配置最佳实践
1. **标签格式规范**:
   - 使用 `//package:target` 格式
   - 避免重复路径如 `//include:include:...`
   - 目标名称应该简洁明确

2. **Include路径处理**:
   - Bazel的`includes`属性用于相对路径
   - 绝对路径使用`hdrs`和`deps`属性
   - 避免在BUILD文件中直接使用include声明

3. **依赖管理**:
   - 明确区分`deps`、`hdrs`、`srcs`的作用
   - 避免循环依赖
   - 使用合适的可见性控制
