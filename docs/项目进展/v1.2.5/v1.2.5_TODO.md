# SQLCC v1.2.5 版本开发计划 - 系统性测试与构建优化

**版本代号**: System Testing & Build Optimization (系统测试与构建优化)
**计划周期**: 2025年12月21日 - 2026年1月21日 (4周)
**核心目标**: 解决 Bazel 重构问题，提升测试覆盖率至 80%+

## 🎯 版本总体目标

基于 v1.2.4 的进展分析，制定系统性的构建和测试优化计划：

### 核心指标目标
- **Bazel构建**: 零错误、零警告，构建时间 < 5分钟
- **测试覆盖率**: 从76.2%提升至80%+ (行覆盖率82%、分支覆盖率75%)
- **构建稳定性**: 建立自动化回归测试，确保长期稳定
- **测试效率**: 测试执行时间减少30%，自动化程度提升50%

### 重点改进领域
1. **Bazel构建系统**: 解决标签错误、include 路径错误、包依赖错误
2. **执行引擎测试**: JOIN、集合操作、窗口函数等核心功能测试完善
3. **分支覆盖率**: 系统化完善条件分支和异常处理测试
4. **边界条件测试**: 网络通信、存储引擎、SQL解析器的异常场景测试

---

## 📋 详细改进计划

### Phase 1: Bazel重构问题解决 (第1周)

#### 🎯 阶段目标
- 全面诊断和修复 Bazel 构建系统问题
- 建立稳定的构建环境，为后续测试工作奠定基础
- 零编译错误、零编译警告

#### 1.1 构建系统深度诊断
**任务内容**:
- [ ] 使用 `tools/test_dependency_analyzer.py` 分析所有 BUILD.bazel 文件
- [ ] 生成详细的依赖关系图和问题报告
- [ ] 识别标签错误、include 路径错误、包依赖错误的具体位置

**预期成果**:
- 完整的构建系统问题清单
- 优先级排序的修复计划

#### 1.2 核心组件构建修复
**任务内容**:
- [ ] 修复 sql_parser 包目标名称不一致问题 (sql_parser vs sqlcc_parser)
- [ ] 规范化 include 路径配置 (../../include → 标准路径)
- [ ] 验证 core、storage_engine、network、execution 包构建状态
- [ ] 清理循环依赖和冗余依赖关系

**预期成果**:
- 所有核心包能够成功编译
- 构建输出无警告信息

#### 1.3 工具链完善
**任务内容**:
- [ ] 增强 `bazel_label_fixer.py` 的批量处理能力
- [ ] 开发 `bazel_dependency_analyzer.py` 依赖关系可视化工具
- [ ] 创建 `bazel_health_monitor.sh` 构建健康监控脚本

**预期成果**:
- 自动化修复工具覆盖主要问题类型
- 构建问题诊断效率提升 70%

### Phase 2: 测试系统重构 (第2-3周)

#### 🎯 阶段目标
- 执行引擎覆盖率从72.1%提升至75%+
- 分支覆盖率从70.0%提升至75%+
- 新增200+测试用例，覆盖边界条件和异常场景

#### 2.1 执行引擎测试深度优化
**任务内容**:
- [ ] JOIN执行器: 新增30+测试用例，提升覆盖率至85%
  - 自连接、同名列处理、复杂JOIN条件测试
  - LEFT/RIGHT/FULL/CROSS JOIN所有类型测试
- [ ] 集合操作执行器: 完善 UNION/INTERSECT/EXCEPT 测试
  - 去重逻辑、多重嵌套、数据类型兼容性测试
- [ ] 窗口函数执行器: 补充 ROWS vs RANGE 框架测试
  - PARTITION BY 多列分区、ORDER BY 排序规则测试
- [ ] 递归查询和函数执行器: 深度限制和参数验证测试

#### 2.2 分支覆盖率专项提升
**任务内容**:
- [ ] 系统化完善条件分支测试 (if/else, switch, 三元运算符)
- [ ] 完善异常处理路径测试 (try-catch, finally)
- [ ] 边界条件测试 (循环边界、递归终止)

#### 2.3 边界条件和异常处理测试
**任务内容**:
- [ ] 网络通信异常场景测试 (连接断开、SSL握手失败)
- [ ] 存储引擎边界条件测试 (磁盘空间不足、内存压力)
- [ ] SQL解析器鲁棒性测试 (语法错误恢复、特殊字符处理)

### Phase 3: 系统集成与优化 (第4周)

#### 🎯 阶段目标
- 建立完整的端到端测试体系
- 性能基准测试完善
- 自动化测试框架升级

#### 3.1 集成测试完善
**任务内容**:
- [ ] 端到端业务流程测试 (用户注册→数据操作→查询分析)
- [ ] 多模块协同工作一致性验证
- [ ] 系统压力负载测试

#### 3.2 测试基础设施现代化
**任务内容**:
- [ ] 自动化测试框架升级 (测试数据生成器、可视化仪表板)
- [ ] CI/CD 集成优化 (GitHub Actions 工作流优化)
- [ ] 覆盖率监控系统完善

#### 3.3 性能基准测试
**任务内容**:
- [ ] 不同负载模式性能测试
- [ ] 内存和CPU使用优化
- [ ] 构建时间优化
