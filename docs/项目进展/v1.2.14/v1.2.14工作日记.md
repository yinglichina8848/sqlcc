### 编译环境优化详情

#### 问题识别
- **并行度过高**: jobs=12 → 可能导致内存竞争和超时
- **内存压力**: local_ram_resources=4096 → 在高并行下可能不足
- **构建超时**: 缺少超时保护机制
- **测试超时**: test_timeout=60 → 对于复杂测试不够用

#### 解决方案实施
- **降低并行度**: jobs=12 → jobs=2 (减少资源竞争)
- **优化内存配置**: local_ram_resources=4096 → 保持充足 (4096MB)
- **构建超时保护**: 新增 build_timeout=1800 (30分钟)
- **调整测试超时**: test_timeout=120 (2分钟，适中超时)

#### 配置变更记录
```
# .bazelrc 优化配置
build --jobs=2              # 从12降到2，避免竞争
build --local_ram_resources=4096  # 保持内存充足
build --build_timeout=1800   # 新增30分钟构建超时
test --test_timeout=120      # 调整为2分钟，适中超时
```

#### BUILD文件修复
- **SQL执行器BUILD**: 修复 src/sql_executor/BUILD.bazel，移除循环依赖
- **核心模块BUILD**: 修复 src/BUILD.bazel，移除缺失的view_manager依赖
- **依赖关系清理**: 消除 execution_context ↔ sql_executor 循环依赖
