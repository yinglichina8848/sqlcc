```bash
# 修复结果验证
python3 tools/test_config_validator.py --output build_verification_report.json
```

### 覆盖率配置
```bazel
# .bazelrc 中的覆盖率配置
coverage --combined_report=lcov
coverage --instrumentation_filter="//src/.*"
coverage --instrumentation_filter="//include/.*"
coverage --copt=-fprofile-instr-generate
coverage --copt=-fcoverage-mapping
coverage --action_env=LLVM_PROFILE_FILE=/tmp/coverage_%p.profraw
```

### 模块覆盖率分析脚本
```bash

./scripts/analyze_module_coverage.sh
```
