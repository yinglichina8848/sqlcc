# SQLCC v1.3.1 测试程序分类分析

## 概述

本报告对 tests/ 目录下的所有测试程序进行分类，按照组件依赖层次重新整理和分析，为生成层次化测试分析报告提供基础。

## 层次划分标准

基于组件依赖关系和功能复杂度，将测试程序分为7个层次：

1. **层次1_基础工具类**：不依赖其他组件的基础工具类（logger, config, exception, basic_types）
2. **层次2_存储引擎基础**：存储引擎核心组件（buffer_pool, disk_manager, page_allocator）
3. **层次3_索引系统**：索引相关组件（B+树, index_manager）
4. **层次4_SQL解析器**：SQL解析相关（lexer, parser, AST）
5. **层次5_执行引擎**：查询执行相关（executor, query_processor）
6. **层次6_网络通信**：网络协议和通信（client/server, protocol）
7. **层次7_高层功能**：集成测试、性能测试、安全测试等

## 测试文件统计

## 分类依据和验证

### 依赖关系分析：
1. **层次1**：仅依赖标准库和基础头文件
2. **层次2**：依赖层次1，可能依赖并发原语
3. **层次3**：依赖层次2的存储引擎基础
4. **层次4**：依赖层次1，可能间接依赖层次2
5. **层次5**：依赖层次4和层次2/3
6. **层次6**：依赖层次5
7. **层次7**：依赖所有层次

### 文件路径模式：
- `unit/basic/` → 层次1
- `storage_engine/` → 层次2/3
- `sql/` 和 `unit/parser/` → 层次4
- `execution/` 和 `unit/executor/` → 层次5
- `network/` → 层次6
- `integration/`, `performance/`, `security/` → 层次7
