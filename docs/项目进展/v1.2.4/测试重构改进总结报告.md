## 🔍 测试代码依赖问题分析

### 主要问题分类

#### 1. Include路径问题 (高优先级)
```cpp
// ❌ 错误示例
#include "sqlcc/core/config_manager.h"  // 多余前缀
#include "sql_parser/lexer_new.h"       // 弃用头文件

// ✅ 正确示例
#include "core/config_manager.h"
#include "sql_parser/lexer.h"
```

#### 2. 依赖关系问题 (中优先级)
```bazel
# ❌ 过度依赖
deps = [
    "//src/utils:utils",  # 包含过多组件
]

# ✅ 精确依赖
deps = [
    "//src/core:core",    # 仅依赖所需
    "@com_google_googletest//:gtest_main",
]
```

#### 3. 构建状态问题 (高优先级)
- **链接错误**: undefined reference to symbol
- **循环依赖**: 包间循环引用
- **缺失依赖**: 需要的库未包含
