## 重构过程详细记录

### 阶段1：.bazelrc 配置完善（已完成）

#### 主要变更：
```bash
# coverage --combined_report=lcov
coverage --instrumentation_filter=^//src
coverage --experimental_use_llvm_covmap
coverage --cxxopt=-fprofile-instr-generate
coverage --cxxopt=-fcoverage-mapping
coverage --linkopt=-fprofile-instr-generate
coverage --test_env=LLVM_PROFILE_FILE=%p.profraw
```

#### 关键配置说明：
- `instrumentation_filter=^//src`：只统计 src 目录，避免统计测试代码
- `experimental_use_llvm_covmap`：Bazel 8 + Clang 20 必须的 LLVM 覆盖率支持
- `%p.profraw`：防止并发测试间文件冲突

#### 经验教训：
1. **路径过滤很重要**：一开始没有正确设置 `instrumentation_filter`，导致测试代码也被统计
2. **版本兼容性**：Clang 20 需要特定的配置选项，不同版本有不同的要求

### 阶段2：BUILD 文件清理（已完成）

#### 主要问题：
- 项目中存在手动添加的 `-fprofile-arcs -ftest-coverage` 等 GCC 风格的覆盖率选项
- 这与 Clang 的 `-fprofile-instr-generate -fcoverage-mapping` 冲突

#### 解决方案：
- 移除了所有手动覆盖率编译选项
- 让 Bazel 在 coverage 模式下自动应用正确的编译选项

#### 经验教训：
1. **不要混合编译器选项**：GCC 和 Clang 的覆盖率选项完全不同
2. **信任 Bazel 的自动化**：Bazel 的 coverage 模式会自动处理编译选项

## 技术经验总结

### Bazel 覆盖率配置最佳实践

1. **正确设置过滤器**：
   ```bash
   coverage --instrumentation_filter=^//src
   ```

2. **使用正确的 LLVM 选项**：
   ```bash
   coverage --experimental_use_llvm_covmap
   coverage --cxxopt=-fprofile-instr-generate
   coverage --cxxopt=-fcoverage-mapping
   ```

3. **避免并发冲突**：
   ```bash
   coverage --test_env=LLVM_PROFILE_FILE=%p.profraw
   ```

### 常见陷阱和解决方案

1. **陷阱：混合 GCC 和 Clang 选项**
   - 现象：编译错误或覆盖率数据丢失
   - 解决方案：移除所有手动覆盖率选项，让 Bazel 自动处理

2. **陷阱：错误的过滤器设置**
   - 现象：统计了测试代码或外部库
   - 解决方案：精确设置 instrumentation_filter

3. **陷阱：测试只调用头文件**
   - 现象：覆盖率报告为空
   - 解决方案：确保测试调用实际的 .cpp 文件中的函数

### 性能和效率提升

1. **并行测试执行**：使用 `%p.profraw` 支持并发测试
2. **增量覆盖率**：只统计需要的源码目录
3. **快速反馈**：HTML 报告提供直观的覆盖率可视化

### 生成命令模板：
```bash
# 1. 运行覆盖率测试
bazel coverage //tests/target:target_test

# 2. 合并 profdata
llvm-profdata-20 merge -sparse $(find bazel-out -name "*.profraw") -o coverage.profdata

# 3. 生成 HTML 报告
llvm-cov-20 show bazel-bin/tests/target/target_test \
  -instr-profile=coverage.profdata \
  -format=html \
  -output-dir=coverage-html \
  -path-equivalence=/proc/self/cwd,$PWD

# 4. 查看报告
xdg-open coverage-html/index.html
```
