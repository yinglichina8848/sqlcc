**详细修复记录**：

#### 1. 循环依赖解决（关键架构重构）
- **问题**：SelectParser需要data_types.h/set_operation.h（在parser库），但parser库依赖select_parser
- **方案**：创建common_ast库包含：
  - `data_types.cpp/h`, `datetime.cpp/h`, `decimal.cpp/h`
  - `set_operation.cpp/h`, `operator_kind.h`
- **依赖链**：common_ast → ast → parser/select_parser

#### 2. API不兼容修复
- **DeleteStatement**：构造函数从`string`改为`vector<string>`
  - 修复：`vector<string> tableNames = {tableName};`
- **WhereClause**：构造函数从3个string参数改为`unique_ptr<Expression>`
  - 临时方案：抛出异常，待Expression架构完整实现
- **InsertStatement**：values从`vector<string>`改为`vector<vector<unique_ptr<Expression>>>`
  - 修复：使用`addValue()`逐个添加值

#### 3. 代码整合与清理
- **删除过时文件**：`parser_set_operations.cpp`
  - 功能已整合到`ParserDML::parseCompositeSelectStatement()`
- **实现新方法**：
  - `ParserDML::parseSetOperationType()`：识别UNION/INTERSECT/EXCEPT
  - `ParserDML::parseCompositeSelectStatement()`：处理集合操作组合
- **修复类型引用**：`operator_mapper.h/cpp`中所有`Token::Type` → `Type`

#### 4. 文件组织优化
- **迁移AST实现文件**：从`src/sql_parser/`移至`src/sql_parser/ast/`
  - `ast_dcl_statements.cpp`
  - `ast_node.cpp`
  - `ast_nodes.cpp`
  - `ast_constraint.cpp`

#### 5. 依赖注入改进
- **ParserDML::Impl类**：
  ```cpp
  class ParserDML::Impl {
      ExpressionParser expr_parser_;
      SelectParser select_parser_;  // 注入expr_parser_依赖
  };
  ```
