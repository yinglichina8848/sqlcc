# SQLCC v1.2.3 核心组件覆盖率分析报告

**生成时间**: 2025年12月19日
**分析范围**: SQLCC核心组件（排除系统库和测试代码）
**覆盖率工具**: Bazel内置覆盖率 + gcov插桩
**统计维度**: 行覆盖率、分支覆盖率、函数覆盖率、类覆盖率

## 1. 覆盖率统计框架概述

### 1.1 统计原则
- ✅ **只统计SQLCC核心源码**: `//src/*` 和 `//include/*` 目录
- ❌ **排除系统库**: 不统计C++标准库、系统调用等
- ❌ **排除测试代码**: 不统计测试文件本身的覆盖率
- ✅ **多维度统计**: 行、分支、函数、类四个维度

### 1.2 配置修改
```bash
# .bazelrc配置 - 只统计SQLCC核心组件
coverage --combined_report=lcov
coverage --instrumentation_filter="//src/.*"
coverage --instrumentation_filter="//include/.*"
```

### 1.3 测试类型覆盖
根据不同类型的测试收集覆盖率数据：
- **单元测试**: `tests/unit/*` - 核心函数测试
- **组件测试**: `tests/components/*` - 模块集成测试
- **验证测试**: `tests/validate/*` - 功能验证测试
- **集成测试**: `tests/integration/*` - 系统集成测试
