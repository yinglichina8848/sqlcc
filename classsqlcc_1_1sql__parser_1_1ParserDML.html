◆ parseCompositeSelectStatement()

std::unique_ptr< ASTNode > sqlcc::sql_parser::ParserDML::parseCompositeSelectStatement ( )

解析复合 SELECT 语句（集合操作）

WHY: 支持 UNION, INTERSECT, EXCEPT 等集合运算以组合多个查询结果。 WHAT: 递归解析左侧 SELECT，识别操作符，解析右侧 SELECT，并构建集合操作树。 HOW:

  1. 调用 parseSelectStatement 获取左子树。
  2. 预读 Token 检查是否存在集合操作关键字。
  3. 若存在，则递归解析右子树并封装为 SetOperation 节点。

std::unique_ptr< SelectStatement > sqlcc::sql_parser::ParserDML::parseSelectStatement ( )

解析 SELECT 语句

WHY: SELECT 是 DML 中最复杂的语句，涉及投影、过滤、连接等多个环节。 WHAT: 将标准的 SELECT 文本转换为 SelectStatement 对象。 HOW: 委托给内部的 SelectParser (select_parser_) 进行专业化子句解析。
